阿地的比對結論

  • 幾乎一致：構圖（地藏左持九環錫杖+寶冠、佛陀右坐蓮花座）、旁白框、兩個對話氣泡、1/12 頁碼位置、暖金色調、苾芻半圓圍繞 —— 兩張高度相同。
  • 代表什麼：當「prompt 一字不差 + 同一張真實參考圖」時，API 與 LoveArt 出圖會非常接近。先前你覺得差異大，主因是之前兩邊命令本來就不同（LoveArt 用一堆網址當參考、超長中文＋禁止清單；API 用真實 ref 像素＋精簡 Copy 清單），不是引擎差。
  • 仍有的細微差：LoveArt 版人物略多、背景樹木與光暈更滿（平台會自行擴寫/補細節）；API 版較貼近 prompt 字面、留白較乾淨。這就是「平台包裝層」殘留的影響。
  • 結論：差異 ≈ 命令結構為主因（可控）＋平台微調為次因（難完全消除）。控制變因後，兩者可逼近到實務上可互換。
