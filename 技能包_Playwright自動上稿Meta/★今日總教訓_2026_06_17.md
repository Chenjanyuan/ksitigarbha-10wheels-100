## 雷 2: navigator.clipboard.writeText + Ctrl+V = 用戶 Ctrl+C 蓋掉

**現象:** 我用 clipboard.writeText 寫入篇 1 文字, 同時阿元 在他電腦 Ctrl+C 複製對話 → **clipboard 被蓋, 篇 1 排程內容變阿海對話**, 必須刪除重排.

**Why:** Windows clipboard 全系統共享.

**Fix:** ★★★ 用 `dispatch ClipboardEvent + DataTransfer` 物件:
```js
const dt = new DataTransfer();
dt.setData('text/plain', text);
editor.dispatchEvent(new ClipboardEvent('paste', {clipboardData: dt, bubbles: true, cancelable: true}));
```
完全不碰 system clipboard, 用戶白天能正常 Ctrl+C/V 做別事 = 0 影響.

## 雷 4: spinbutton fill / type 沒效, 只接受 ArrowUp/Down 鍵盤事件

**Why:** Meta UI 的 spinbutton 是 React 控制, `fill('07')` 不生效, JS 合成 KeyboardEvent 也不生效.
**Fix:** 用 Playwright `browser_press_key('ArrowUp')` (真實 keyboard event), 連按多次到目標值.
- 0 → 8 = ArrowUp × 8
- 51 → 0 = ArrowUp × 9 (跨進位 — 小時 +1, 再 ArrowUp 7 次補回 8)

## 雷 7: 子資料夾「圖片」內的圖

**現象:** 阿元 從篇 4 開始把圖放在 `每篇貼文/{篇}/圖片/` 子資料夾, 不是根目錄. 我的 check_post.py 只找根目錄, **誤判篇 4 沒圖**.

**Fix:** check_post.py 加 fallback 找子資料夾「圖片」:
```python
imgs_root = sorted([f.name for f in folder.glob("*.png")])
imgs_sub = sorted([f.name for f in (folder/"圖片").glob("*.png")]) if (folder/"圖片").exists() else []
imgs = imgs_root if imgs_root else imgs_sub
```
