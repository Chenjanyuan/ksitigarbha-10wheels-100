## 🔴 新踩的雷 + 解法

### 雷 12 — Playwright MCP allowed_roots 真擋專案路徑(2026-06-18)

**現象:**
```
Error: File access denied
C:\Users\chenj\Documents\Claude\Projects\...\01_xxx.png
is outside allowed roots.
Allowed roots: C:\Users\chenj\AppData\Local\Temp\.playwright-mcp
```

**之前誤判:** 阿研技能說「直接給 Windows 絕對路徑就行」— **實測不行**。Playwright MCP 安全機制就是擋。

**解法:** 用 PowerShell .ps1 cp 12 張到 `C:\Users\chenj\AppData\Local\Temp\.playwright-mcp\pian<N>\`,然後上 Temp 路徑。

★ **PowerShell .ps1 要含 UTF-8 BOM**,否則中文路徑亂碼 — 記憶檔 `feedback_ps1_utf8_bom.md` 早就警告過。
★ `Get-ChildItem` 用 `-Include` 要配 `-Recurse` 或路徑加 `\*`,否則回 0 張。最穩用 `-Filter '*.png'` 分別跑。

完整工具:`cp_pian1.bat`(專案根目錄)— 阿元雙擊一次 = 12 張到 Temp ✅

### 雷 13 — Meta spinbutton 真實值看 `aria-valuenow` 不是 `value`(2026-06-18)

**現象:**
按 ArrowUp 8 次,JS 讀 `input.value` 還是空字串 — **誤判 ArrowUp 沒效**,結果按了 16+ 次。

**真相:** Meta spinbutton 用 React 控制,value 屬性永遠是空,真實值在 `aria-valuenow`:
```js
const hour = document.querySelector('input[aria-label="小時"]');
hour.getAttribute('aria-valuenow')  // "8" ✅
hour.value  // "" ❌ 別看這個
```

**設小時 08 的真相:**
- 點開時 spinbutton 預設「當前時間+N 小時」(凌晨點開可能是 16)
- 算差距 → ArrowDown × diff(從 16 到 8 = ArrowDown × 8)
- ★ **改進版**:用 `aria-valuenow` 算正確差距,別盲按

**設分鐘 00:**
- 點開時是「當前分鐘」(48 之類)
- 從 X → 0 最少 = ArrowUp × (60-X) 翻過 60 wraparound
- 但 wraparound 會帶動小時 +1 → 後續再 ArrowDown 校正

### 雷 15 — Meta 圖片處理時間長,「排定時間」按鈕長時間 disabled

**現象:** 12 張圖 file_upload 完成後 30+ 秒,「排定時間」仍 `aria-disabled="true"`,頁面顯示「**請稍待片刻……**」

**等待時間:** 可能 1-2 分鐘,因為 12 張 1024x1024 大圖需要 Meta server 處理。

**判定方法:**
```js
/請稍待片刻/.test(document.body.innerText)
// 還在 = true,等
// 不在 = false,可點排定時間
```
