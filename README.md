# 📿 地藏十輪經 100 篇 FB 連載

> 由 阿元 + 阿地 + 阿美 一起做的佛法事業 🪷
>
> 把《大乘大集地藏十輪經》拆成 100 篇，每篇 12 張吉卜力風格的圖 + 一段大白話講解，
> 每週一到週五早上 8:00 自動排程到 FB 粉專。
>
> FB 粉專: [地藏菩薩本行經](https://www.facebook.com/Ksitigarbhabodishava)

## 📂 資料夾結構

```
├── 每篇貼文/               ★ 100 篇核心 — 每篇含 docx + 生成命令.md + 12 張圖
├── 阿地交接/               阿地 (Claude) 接班用文件
├── 經文/                   經書原文 (PDF + 繁體 txt)
├── 人物角色卡/             12 個角色卡 PNG
├── review.py / fb_auto.py  FB 排程工具 (Flask UI + Graph API)
├── 100篇上刊日清單.csv     新日曆 (5/26 ~ 10/16)
├── 100篇大綱.md            100 篇劇情大綱
├── 標準模板_2026-05-22.md  2700 字標準生成模板
├── CLAUDE.md               專案規則
└── 資料夾說明.md           完整地圖
```

詳細導覽看 [資料夾說明.md](資料夾說明.md)

---

## 🎯 每天工作流

```
1. 打開 每篇貼文/<今天日期>_第N篇_*/生成命令.md
2. 複製 → 貼到 LoveArt (阿美 — Nano Banana Pro)
3. 阿美 出 12 張圖 → 一張一張檢查
4. 12 張 PNG 命名為 01_xxx.png ~ 12_xxx.png 存回同資料夾
5. 啟動 review.py (http://localhost:5000) → 看圖 → 點【排程到 FB】
```
