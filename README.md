## 🛠 製作流程（守 CLAUDE.md 死命令）

1. 讀該篇 `每篇貼文/…/` 貼文 docx → 對照貼文拆 12 格分鏡（白話、不扭曲經文）
2. Panel 1 做到完美當「定裝種子」 → Panel 2-12 用 Sequential Art 滾動參考
3. 每張 prompt 必帶 **7 段骨架**（風格 ref＋場景＋**比例 1:5-7 不巨人**＋**地藏官方寶冠九環造型**＋畫風＋單一氣泡繁體＋頁碼）
4. 一張一張送、送完驗證、自查（繁體／單一氣泡無亂碼／造型／比例／頁碼）
5. 下載存檔 → 寫 docx → GitHub 交接

詳見 `技能包_AI連環漫畫角色一致性/SKILL.md` 與 `阿地交接/`。
