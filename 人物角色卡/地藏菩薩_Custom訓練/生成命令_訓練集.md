# 地藏菩薩 Custom Character 訓練集 — 生成命令

> 目的: 用一張官方 ref 鎖定 → 生 15 張「乾淨定裝照」(不同角度/表情/姿勢) → 嚴格篩選 → 上傳 LoveArt Custom Character 訓練 → 之後 @地藏菩薩 呼叫 >90% 一致。
> ⚠️ 訓練圖鐵則: **素色/簡單背景、無對話氣泡、無旁白、無頁碼、單一角色**。每張肉眼確認寶冠九環+同臉+比例正常, 漂移的丟掉重生。

## 共用造型描述(每張帶, 鎖造型)
漢傳五瓣寶冠(五小佛)、白布披雙肩、右手九環錫杖(三叉每叉3環)、深芥末褐袈裟+綠腰帶、淡金膚、眉心白毫、柔和金光暈、圓潤慈眉微笑、正常人類比例1:5-1:7。**素色柔光背景, 單一角色, 無文字無氣泡無頁碼。** 全繁體(本圖不需文字)。跟參考圖同一張臉同造型, 不可漂移。

## 15 張命令(一張一張送, 每張生完篩選)

1. **正面全身・合掌站立** — 地藏菩薩正面直立, 雙手胸前合掌, 莊嚴。
2. **正面臉部特寫・垂目微笑** — 半身近景, 慈悲垂目淺笑, 寶冠白毫清楚。
3. **3/4 側・持九環錫杖站立** — 四分之三側身, 右手持九環錫杖立地。
4. **正側面輪廓・行走** — 完整側面, 邁步行走, 飄帶天衣流動。
5. **坐姿・說法手勢** — 結跏趺坐於巨石蓮花座, 一手結說法印。
6. **救度・伸手** — 微前傾, 一手向前伸出, 眼神溫暖慈悲。
7. **背側 3/4・顯示披肩白布** — 略背向回眸, 顯示寶冠與白布覆雙肩。
8. **仰視天空・慈悲相** — 微仰首望上方, 金光暈環繞。
9. **雙手捧寶珠** — 正面半身, 左手托明亮寶珠, 右手錫杖。
10. **頂禮彎身・謙敬** — 向前微彎身頂禮姿態(表現謙遜)。
11. **雲端立姿・飄帶** — 立於淡金祥雲上, 天衣飄帶舒展。
12. **正面半身・莊嚴定相** — 正面胸像, 平視, 寶冠瓔珞細節清楚。
13. **微側・閉目禪定** — 微側面, 閉目寧靜禪定, 雙手定印。
14. **標準像・錫杖+寶珠全身正面** — 正面全身, 右錫杖左寶珠(角色卡標準站姿)。
15. **4/5 側・淺笑半身** — 接近正面的側角, 溫和淺笑, 自然光。

## 之後步驟
1. 15 張生完 → 阿地幫篩, 留 10-20 張造型一致的, 存到 `訓練集/` (命名 訓練_01.png ~)。
2. LoveArt 找 Custom Character / Train a Character → 上傳這批 → 命名「地藏菩薩」→ 訓練 30-60 分。
3. 訓練好 → 之後 prompt 用 `@地藏菩薩`, 不再每張貼 URL。
4. 其他主角(佛陀/觀音…)同法可做。
