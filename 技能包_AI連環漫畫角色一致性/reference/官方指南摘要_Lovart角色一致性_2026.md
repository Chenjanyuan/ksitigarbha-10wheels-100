## 為什麼角色會漂移
AI 圖像生成器不「認識」你的角色。擴散模型每個 seed 從雜訊去噪, 同 prompt 兩次也會在細節累積成不同臉。真正無限一致仍是研究邊疆。

## 技術排行(官方, 含一致性 %)
| 技術 | 一致性 | 備註 |
|---|:--:|---|
| **角色鎖定 (Lovart 上傳參考圖當錨點)** | ~85% (20張內) | 速度同標準流程, 整合佳 |
| IP-Adapter (Stable Diffusion) | ~80% | 需本地端設定 |
| 固定種子+詳細提示 | ~60% | 脆弱, 改一字就破 |
| **換臉後製 (face-swap)** | ~90% 臉 | 遠景好, 特寫光線不合會像合成 |
→ 專業做法 = **多技術疊加**: 角色鎖定生成 → 換臉清漂移 → 手動修最後 5%。

## 參考圖需求(關鍵省成本)
- **一張優質 ref 就夠**: ≥1024×1024、光線足臉清楚、正面或 3/4 側、**背景單純**(複雜背景會干擾鎖定)。
- 多張(2-3不同角度)只多 **5-10%**, 非必要。

## 角色設定表 / 漫畫工作流
1. 生基礎角色(乾淨正面全身) → 2. 鎖定 → 3. 生其他視角(「同一角色, 3/4側, 同服裝」) → 4. 拼到單一畫布、**手動加文字標籤**(AI 文字不準) → 5. 手動修不一致(預留 30-45 分)。
- 漫畫: 鎖定生每格 → **接受 ~15% 會漂移** → 漂移格用換臉修 → 拼格手動加對話框 → 最後統一色彩校正+線條粗細。

## 自訂角色訓練(最穩, 長期 ROI)
- 上傳 **10-20 張**不同圖到 Lovart Custom Character → 訓練 **30-60 分** → @角色名呼叫, **>90% 一致**, 永久存帳號。
- **50 張以上會出現的角色都該做**(地藏菩薩正適合!)。

## 失敗率管理
- 預期 **10-20% 鎖定生成會肉眼漂移**。
- 每場景**批次生 5-10 張**、**嚴格篩選**(略有不對就刪)、特寫用換臉、**多預留 20-30% 生成次數**。

## 🌟 多數指南不講的 3 件事
1. **一致性會放大微小錯誤**: 參考圖的小不對稱在 50 張裡會變「定義特徵」→ 鎖定前用 **200% 放大檢查參考圖**, 先修不對稱。
2. **服裝比臉難**: 鎖定保臉好, 但領口/鈕扣/布紋會變 → **服裝獨立鎖一張 ref**(我們做法), 官方更建議基礎姿勢生好再用數位時尚工具統一穿衣。
3. **85% 法則**: 50 張以上不可能 100%。接受 85% 天花板, 預留 15% 修圖時間就出貨。**追 100% 是完成的最大敵人。**

## ⚠️ 風格一致 ≠ 角色一致
很多工具號稱「角色一致」其實只是「風格一致」(同畫風的動漫臉)。我們要的是**同一個個體跨格同臉**(角色一致), 難得多。

## 對我們地藏專案的應用
- 已用: 一張官方 ref 鎖定、Sequential 滾動參考、服裝獨立、85% 法則(全在 SKILL.md)。
- **可考慮**: 為地藏菩薩做 **Custom Character 訓練**(100 篇必出, >90% 一致, 一勞永逸); 特寫漂移可用換臉後製補。
- ⛔ 地藏造型一律官方**寶冠九環**, 不用任何通用範例的光頭橙袍。
