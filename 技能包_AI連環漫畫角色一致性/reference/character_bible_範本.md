# Character Bible 空白範本

> 任何角色都用這個範本填。阿狗做 WhatDog 狗狗主角，直接複製本檔填。
> 填好後，每次寫 prompt 從這份「複製細節」，不靠記憶 → 角色不漂移。

```markdown
# [角色名] Character Bible

## 基本
- 設定: [一句話定位，例: 忠誠勇敢的柴犬主角 / 慈悲堅定的智者]
- 性格: [3 個關鍵詞]
- 視覺年齡感: [幼犬 / 成犬 / 永恆相 ...]

## 外型（鎖死，不可變）
- 頭型/臉型: 
- 毛色/膚色: [具體色號或形容，例: 薑黃色短毛、白色胸斑]
- 體型: 
- 特徵記號: [最強的視覺錨點 — 例: 左耳缺口、眉心白毫、特定花紋]
- 眼睛: 

## 服裝/配件（最會變，要最詳細 — 另存一張特寫當 ref）
- 主要服裝/項圈: 
- 顏色: 
- 配件/道具: [例: 紅領巾、錫杖9環、寶珠]
- 永遠有的東西: 

## 神情範圍
- 預設: 
- 開心/說法: 
- 緊張/救度: 

## 色彩
- 主色: 
- 配色: 
- 禁色: 

## 動作
- 可: 
- 不可: 

## 一句話「鎖定咒」（每張 prompt 開頭貼）
「主角 = [角色名]，[最關鍵 3 特徵]，跟參考圖完全一致，不可改。」
```

## 填寫提醒
1. **特徵記號越獨特越好**（缺口耳、特殊花紋、寶冠）→ 鎖得越強。
2. **服裝/項圈一定要單獨生一張特寫**當參考圖（服裝比臉難固定）。
3. 鎖定前把參考角色放大 200% 檢查不對稱 — 一致性會放大微小錯誤，現在不修就要跟它共存 50 張。
4. 出現在 50 張以上 → 直接訓練 Custom Character（>90% 一致）。
