## 🔑 LoveArt 上傳 reference 的「**正確 3 步驟**」

### Step 1: 上傳 reference 圖到「**Image Reference 槽位**」(不是對話框)

- 找介面上的 **「Image Reference」** 按鈕
- 或者在輸入 prompt 時打 **`@`** → 跳出 reference 選單
- 選你預先生好的角色 reference

⚠️ **注意**: 直接把圖拖進「對話框」≠ 上傳到「reference 槽位」!
這就是阿地以前覺得「沒什麼用」的真正原因。

### Step 2: 設定「**Influence Strength**」到 **60%**

- 官方推薦數值: **60%**
- 太低(30%): 不夠被參考, 角色又變了
- **60% 是最佳平衡點** ✅
- 太高(90%): 變成「全部抄圖」, 失去創意空間

⚠️ 如果阿地之前**沒調這個**, 預設可能太低 → 這是「沒什麼用」的另一原因

### Step 3: Prompt 內明確「**call** reference」

不要只寫「請參考這張」, 要寫:

```
[場景描述]
使用 reference 中的同一個角色 (use the @[reference 名] character)
exact same outfit
exact same face
```

## 🌟 進階技巧 — **多 reference 混合**

LoveArt 最強的功能: 一次可以鎖 **最多 14 張 reference**!

阿地可以這樣分:

```
Reference 1: 主角的「臉部特寫」  ← 鎖臉
Reference 2: 主角的「全身服裝照」 ← 鎖衣服 (你之前缺這個!)
Reference 3: 場景的「全景照」    ← 鎖場景
Reference 4-5: 其他配角         ← 鎖配角
```

⚠️ **超關鍵發現**: 之前阿地可能**只給角色圖**, 沒給「**服裝特寫**」當獨立 reference, 所以 AI 自由發揮 → 衣服變了!

**修正**: 把「主角的長袍特寫」**獨立**生一張, 上傳當 reference 2

## 🔍 LoveArt 「Lock onto Soul」概念(白話)

Lovart 官方說:
> "Nano Banana will 'lock' onto it. Change the lighting, the angle, or the outfit, **but the 'Soul' of the subject remains untouched.**"

意思: Reference 是鎖**「主體靈魂」**, 不是拷貝圖。

- 想鎖「**臉部**」→ reference 給「**臉部特寫**」
- 想鎖「**服裝**」→ reference 給「**服裝特寫**」(這層阿地之前可能漏了)
- 想鎖「**場景**」→ reference 給「**場景全景**」

## 📝 阿地的「**新工作流 SOP**」(每章開始時做)

### 一次性準備(每章只做 1 次, 約 30 分鐘)

1. **生「角色卡」**: 主角 neutral 站立, 三視圖(正/側/背)
   → 存檔 `角色-主角-臉部-reference.png`
2. **生「服裝特寫」**: 主角的法袍細節(領口/腰帶/袖口特寫)
   → 存檔 `角色-主角-服裝-reference.png`
3. **生「場景全景」**: 主要場景 1-3 張(山洞 / 寺廟 / 路上)
   → 存檔 `場景-山洞-reference.png` 等

### 每張 panel 生成

1. 開新 chat
2. **上傳到 Image Reference 槽位**(不是對話框):
   - 主角臉部 reference
   - 主角服裝 reference  ← 阿地新增的!
   - 場景 reference
3. **Influence Strength: 60%** (主要 reference) / 80% (服裝 reference, 提高)
4. **Prompt**:
   ```
   [場景描述, 例如「山洞前」]
   [動作描述]
   Use @主角-臉部-reference for character face,
   use @主角-服裝-reference for exact same outfit (no changes),
   use @場景-山洞-reference for environment.
   ```
