## 6.2 ✅ Python 範本(urllib)

```python
import urllib.request
from pathlib import Path

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 (KHTML, like Gecko) "
                  "Chrome/130.0.0.0 Safari/537.36",
    "Accept": "image/*,*/*;q=0.8",
    "Referer": "https://www.lovart.ai/",  # ★ 沒這行會 403
}

URLS = [
    "https://a.lovart.ai/artifacts/agent/xxx1.png",
    # ... 12 個
]

OUT_DIR = Path(__file__).parent / "圖片"
OUT_DIR.mkdir(exist_ok=True)

ok = 0
fails = []
for i, url in enumerate(URLS, 1):
    fn = OUT_DIR / f"{i:02d}_{url.split('/')[-1]}"
    try:
        req = urllib.request.Request(url, headers=HEADERS)
        with urllib.request.urlopen(req, timeout=30) as r:
            fn.write_bytes(r.read())
        print(f"✅ {i}/{len(URLS)}: {fn.name}")
        ok += 1
    except Exception as e:
        print(f"❌ {i}/{len(URLS)}: {e}")
        fails.append(url)

print(f"\n成功 {ok} / 總數 {len(URLS)}")
if fails:
    print("失敗清單:")
    for u in fails: print(f"  {u}")
```

# 第 7 章 — 十齋日上稿 SOP(297 次固定文字)

## 7.1 什麼是十齋日

農曆每月 **1 / 8 / 14 / 15 / 18 / 23 / 24 / 28 / 29 / 30** 日。

阿元拍板(2026 起):
- 早上 **6:00**(比連載早 2 小時)上稿
- 每個十齋日用**不同十齋日圖片**(10 種,輪流)
- **加上固定文字**(阿元給的長串文案)
- 不影響每週 5 天連載
- ⚠️ 297 次 = 大約 30 個月份(2.5 年)

## 7.2 固定文字(阿元 2026-06-22 拍板)

完整文字見專案資料夾 `十齋日/固定文字.txt`,含:
- 隱私政策 · 服務條款 · 廣告 · Ad Choices · Cookie ·(navigation 區)
- 精選 / 貼文 / Facebook 重複導引
- 經文原文:「復次普廣...能於是十齋日...對佛菩薩諸賢聖像前讀是經一徧...」

⛔ **絕對不改動文字**(這是阿元手抄整理,不能擅自精簡)

## 9.4 排程腳本(自動算)

```python
from datetime import date, timedelta

TW_HOLIDAYS_2026 = {
    '2026-01-01',
    '2026-01-27','2026-01-28','2026-01-29','2026-01-30','2026-01-31',
    '2026-02-01','2026-02-02','2026-02-03','2026-02-04',  # 春節
    '2026-02-27','2026-02-28','2026-03-01',  # 和平紀念日
    '2026-04-02','2026-04-03','2026-04-04','2026-04-05','2026-04-06',  # 清明
    '2026-05-01',
    '2026-05-30','2026-05-31','2026-06-01','2026-06-02',  # 端午
    '2026-09-24','2026-09-25','2026-09-26',  # 中秋
    '2026-10-09','2026-10-10','2026-10-11',  # 國慶
}

def is_workday(d):
    if d.weekday() >= 5: return False  # 週六日
    if d.isoformat() in TW_HOLIDAYS_2026: return False
    return True

def gen_schedule(start, n_posts):
    """從 start 開始,排 n_posts 篇,跳週末+假日"""
    schedule = []
    d = start
    for i in range(1, n_posts + 1):
        while not is_workday(d):
            d += timedelta(days=1)
        schedule.append((i, d))
        d += timedelta(days=1)
    return schedule

# 100 篇從 2026-06-23 開始
for i, d in gen_schedule(date(2026, 6, 23), 100):
    print(f"篇 {i}: {d.isoformat()} ({['一','二','三','四','五','六','日'][d.weekday()]})")
```
