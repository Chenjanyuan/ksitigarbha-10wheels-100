## 2. 死命令清單

### ⛔ 死命令 -1 — 阿美卡住立刻 Reload(2026-05-29)

阿美 5+ 分鐘無回應 → `window.location.reload()` → 等 5~10 秒 → 重 paste + Enter。
- 一次 reload 為限,不連續
- Reload 後若觸 CAPTCHA → 等阿元勾

### ⛔ 死命令 0 — LoveArt Send 用 Enter Key(2026-05-29 阿地 5 號)

★★★★★ **永遠用 Enter,絕不點 send button!**

```
1. JS: editor.focus()
2. JS: DataTransfer paste prompt
3. chrome computer.key "Return"  ← Enter 觸發 send (CDP 真實 keystroke, isTrusted=true)
4. 等 3 秒
5. JS check editor.innerText.length === 1 = 送出成功
```

❌ **絕對禁止**:`sendBtn.click()` / `left_click [send 座標]` / `Ctrl+Enter`

### ⛔ 死命令 1 — 禁止刪除任何 FB 內容

絕對禁止刪除:FB 貼文、圖片、留言、unpublished posts、scheduled posts、Meta Business Suite 排程內容。

唯一例外:阿元在聊天中**親自打出**「**確認刪除**」字樣 + 阿地**二次確認** + 阿元第二次確認後才能執行。

### ⛔ 死命令 2 — 魔法咒語恢復記憶系統

阿元講以下任一咒語 → 阿地必須**立刻按 SOP 執行**:

主咒語:**「恢復記憶」/「阿地醒醒」/「接班」/「續班」/「載入快照」**
副咒語:「100 篇開工」/「地藏專案開始」/「今天接著做」/「從哪繼續」/「阿地你失憶了嗎」

→ 看 [第 12 章 — 接班 3 步驟](#12-接班-3-步驟)

### ⛔ 死命令 3 — 不准簡體字 / 不准扭曲佛經 / 不准角色漂移

繁體中文是鐵則。阿美預設簡體,**每次命令必寫「全繁體無簡體無錯字」**。

### ⛔ 死命令 4 — Windows .bat 下載圖片不死法(2026-06-20)

任何下載圖片到本機,一律用標準範本(見 [第 6 章](#6-圖片下載-sop))。

### ⛔ 死命令 5 — Meta 多圖上傳檔名鐵則(2026-06-20)

絕對禁止 `01_第6篇12之1_主題.jpg`(「12之X」字串撞亂排序),一律用 **`pianN_NN.jpg`** 純淨檔名(見 [第 5 章](#5-meta-上稿-sop))。

### ⛔ 死命令 6 — LoveArt 畫布 @角色卡參考圖絕不能刪

ctrl+a/Backspace 清空 editor 時若焦點跑到畫布會誤刪參考圖!
- clear 前先 `e.click(); e.focus()` 確保焦點在文字框
- clear 後截圖確認畫布左側參考圖還在
- ⛔ 絕對禁止在 LoveArt 用 Ctrl+A

### ⛔ 死命令 7 — LoveArt @角色卡必須點選成 chip 不可純文字(2026-06-04)

阿美親口:純文字 @ 看不到圖會漂移; 要從下拉選單**點卡變 chip**(出現 For Image#N:URL)才鎖得準。

### ⛔ 死命令 8 — 一張「真的出圖」才送下一張

不是只看 busy→idle,要**親眼看到**:
1. 阿美回「讓我生成」
2. 「生成中」
3. 「創作完成」+ **真的多一張 N/12 圖**

三者齊備才算完成。

### ⛔ 死命令 9 — 上刊日期一律 ls 資料夾,絕不准算/猜品名(2026-06-20)

任何提到「篇 N 日期」「品名」 → 先 `bash ls 每篇貼文/ | grep 第N篇` → 用真實資料夾名(yyyy-mm-dd_第N篇_品)。

**品名分界**:1-20序品 / 21-40十輪 / 41-55無依行 / 56-70有依行 / 71-78懺悔 / 79-88善業道 / 89-95福田相 / 96-100獲益囑累

### ⛔ 死命令 10 — 每篇上稿必做「1:1 套用到全部」(2026-06-20)

Meta default 預覽是 1.91:1 會把方圖切成橫條(右下角編號被裁)。SOP:file_upload 後 → 點編輯相片 → 1:1 → 套用到全部 → 套用。

### ⛔ 死命令 11 — FB 12 張圖序依右下角編號,不可依檔名字母序(2026-06-20)

篇 4+ 檔名「第N篇12之X」沒 0 padded → Meta 排序變 1,10,11,12,2,3... 錯亂!解法用 Codex JPG+EXIF+0padded 法。

### ⛔ 死命令 12 — FB 貼文上稿排版必須逐篇人眼檢查(2026-06-20)

機械套腳本不夠,每篇 paste 進 composer 後必須 dump innerText 檢查 max_blank_run=2 才算對。

### ⛔ 死命令 13 — 寫作禁用收割/割/殺/韭菜(2026-06-20 阿傳廣播)

改用 **捕捉 / 擷取 / 獲利 / 對手方**。所有 AI 寫稿都遵守(地藏連載 / FB 貼文 / 內部交接)。連動 [[feedback_no_donation_words]] — 不寫結緣助印 / 贊助字眼。

### ⛔ 死命令 14 — 構圖變化原則 + 國際電影大片風格

角度 / 主角 / 視角輪流,像 Hollywood / IMAX / 諾蘭《奧本海默》。

### ⛔ 死命令 15 — 同一故事角色一致性

同一篇 12 張內角色造型一致(MUST),100 篇之間同一菩薩造型一致(SHOULD)。

## 3. 100 篇連載專案總覽

### 3.1 專案目標

把《地藏十輪經》(10 卷 8 品,比《地藏菩薩本願經》厚 4-5 倍)用 100 篇白話圖文連載,每天早上 8:00 自動發到 FB 粉專「地藏菩薩 經典導讀」。

### 3.2 上稿節奏(2026-06-20 拍板)

- **每週 5 天**上稿(週一~週五),週末跳
- **跳國定假日**(用中華民國 115 年 / 116 年行事曆)
- 早上 **8:00** 上稿(可預先排程)
- **十齋日**早上 **6:00** 加碼上稿(固定文字 + 不同十齋日圖)
