## 5.3 ⛔ 死命令 5 — 純淨檔名鐵則

血淚教訓(篇 6):
- 檔名 `01_第6篇12之1_佛陀讚嘆.jpg` → Meta UI 把整個檔名納入排序 → 「12之10」可能排到「12之1」附近 → **圖序錯亂**!

### ✅ 唯一正確命名
```
pian{N}_01.jpg
pian{N}_02.jpg
...
pian{N}_12.jpg
```

★ 規則:
- 開頭 `pian{N}_`(N = 篇號)
- 接 **0-padded** 編號 `01` ~ `12`(`02` 不是 `2`)
- **不接主題名**
- EXIF DateTimeOriginal 遞增(08:00:01 → 08:00:12)
- 格式 JPG(非 PNG)

### 工具:make_fb_ordered_jpg.py(v2)
```bash
py make_fb_ordered_jpg.py --serial N --start "yyyy-mm-dd 08:00:00"
```
自動產 `pianN_01.jpg ~ pianN_12.jpg` + EXIF + 0padded

## 5.7 完整上稿 9 步 SOP

### Step 1 — 開粉專層級的新建貼文
```javascript
await browser_navigate("https://business.facebook.com/latest/posts/published_posts?asset_id=1093357677358320");
await browser_click('button:has-text("建立貼文")');  // 粉專層級主要按鈕
// ⛔ 不要點 composer CTA(會跳到單圖編輯)
```

### Step 2 — 上傳 12 張圖
```javascript
await browser_file_upload([
  "C:/.../pian5_01.jpg",
  "C:/.../pian5_02.jpg",
  // ... pian5_12.jpg
]);
await browser_wait_for({ time: 5 });

// ★ poll 法等推銷 dialog(2026-06-20 阿研發現)
for (let i = 0; i < 10; i++) {
  const dialog = await page.$('div[role="dialog"]:has-text("升級")');
  if (dialog) await dialog.$('button:has-text("以後")')?.click();
  await wait(1);
}

// 驗證 12 張全上(listitem 不 filter size)
const items = document.querySelectorAll('[role="listitem"]');
console.assert(items.length === 12, `只上 ${items.length} 張`);
```

### Step 3 — 1:1 套用全部(死命令 10)
```javascript
await browser_click('button:has-text("編輯相片")');
await browser_click('button:has-text("1:1")');
const switchEl = await page.locator('[role="switch"]:near(text="套用到全部")');
if (await switchEl.getAttribute('aria-checked') === 'false') {
  await switchEl.click();
}
// 驗證
await wait(1);
console.assert(await switchEl.getAttribute('aria-checked') === 'true');
await browser_click('button:has-text("套用")');
```

### Step 4 — Paste 貼文文字
```javascript
const text = await fs.readFile(`每篇貼文/yyyy-mm-dd_第N篇_品/FB貼文純文字.txt`, 'utf-8');
const composer = await page.locator('[contenteditable="true"]:has-text("Start with")');
await composer.click();
await composer.fill(text);  // 或 page.keyboard.type(text)

// 排版人眼檢查(死命令 12)
const finalText = await composer.innerText();
const blanks = finalText.match(/\n{3,}/g);
console.assert(!blanks, `空行 ${blanks?.length} 處超過 2`);
```

### Step 5 — 設定排程時間
```javascript
await browser_click('button:has-text("排程")');
// 選日期(MM/DD/YYYY)
await browser_type('input[name="date"]', "06/25/2026");
// 選時間(早上 8:00)
await browser_click('button[aria-valuenow]');  // time picker
// 用 aria-valuenow 設 8:00
await page.evaluate(() => {
  const hour = document.querySelector('[aria-valuenow][aria-label*="hour"]');
  hour?.setAttribute('aria-valuenow', '8');
});
```

### Step 6 — 確認版面

### Step 8 — 驗證已排程

★ 阿地自動延伸 → 算下一個工作日

### 排程腳本
```python
from datetime import date, timedelta
import holidays  # pip install holidays

tw_holidays = holidays.TW()
custom_off = ['2026-02-27', '2026-02-28', '2026-04-02', ...]  # 補休/連假調整

def next_workday(d):
    while True:
        d += timedelta(days=1)
        if d.weekday() >= 5: continue  # 週六日
        if d in tw_holidays: continue
        if d.strftime('%Y-%m-%d') in custom_off: continue
        return d

# 從 2026-06-23 篇 1 開始,每篇 +1 工作日
start = date(2026, 6, 23)
for i in range(1, 101):
    print(f"篇 {i}: {start.isoformat()}")
    start = next_workday(start)
```
