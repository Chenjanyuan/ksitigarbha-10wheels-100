## ✅ 本棒完成內容

### 問題診斷與修復

**問題**: `download_23to29.bat` 閃退，視窗一開即關

**根本原因**: `download_23to29.ps1` 缺少 UTF-8 BOM
- PowerShell 5.1 預設用 ANSI/CP950 讀取無 BOM 的 PS1 檔案
- 含中文的路徑字串 `$BASE = "C:\Users\chenj\...\自動化..."` 被亂碼解析
- 腳本第一行就 ParserError → 立即退出

**修復方法**: 用 bash Python 在 PS1 頭部加入 UTF-8 BOM bytes (`\xef\xbb\xbf`)
```bash
python3 -c "
with open('download_23to29.ps1', 'rb') as f: content = f.read()
with open('download_23to29.ps1', 'wb') as f:
    f.write(b'\xef\xbb\xbf')
    f.write(content)
"
```

**驗證**: 阿元確認「可以了 直接執行 ps1就可以了」✅
