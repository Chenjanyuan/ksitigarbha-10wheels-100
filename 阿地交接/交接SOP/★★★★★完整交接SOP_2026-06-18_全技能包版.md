## 1. 技能一：Playwright 上稿 FB（Meta Business Suite 排程）

- **用 Playwright MCP 操作 Meta UI** -- Meta 看到的是「真人在介面操作」，沒有 AI 標籤
- Playwright MCP 連到阿元自己的 Chrome（有 Meta 登入 session），不用重新登入

### 粉專資訊

- 粉專名：地藏菩薩本行經

為什麼：阿元同時 Ctrl+C 會蓋掉 clipboard，篇1就踩過這雷。

```javascript
// browser_evaluate 內執行：
() => {
  const text = `{fb_post_text}`;
  const editor = document.querySelector('[contenteditable="true"]');
  editor.focus();
  const dt = new DataTransfer();
  dt.setData('text/plain', text);
  const ev = new ClipboardEvent('paste', {clipboardData: dt, bubbles: true, cancelable: true});
  editor.dispatchEvent(ev);
  return {len: editor.textContent.length};
}
```

### 從 docx 抓 FB 貼文文字（Python）

```python
from docx import Document
doc = Document('路徑/貼文內容.docx')
capture = False
lines = []
for p in doc.paragraphs:
    text = p.text.rstrip()
    if not text:
        if capture: lines.append("")
        continue
    is_heading = p.style.name.startswith("Heading")
    if "FB 貼文文字" in text:
        capture = True
        continue
    if capture and is_heading:
        break
    if capture:
        lines.append(text)
fb_post_text = "\n".join(lines).strip()
import re
fb_post_text = re.sub(r"\n{3,}", "\n\n", fb_post_text)
```

## 2. 技能二：LoveArt @角色卡生圖命令法

### 核心概念

在 LoveArt 用 Nano Banana Pro 引擎，把「@點選好的角色卡 + @色彩飽和度 + @一般人物」塞進結構化故事 prompt，一張一張、出圖了才送下一張，生出繁體對白+頁碼+高飽和、角色不漂移的完成稿。

### 三大血淚鐵律

#### 鐵律一：角色卡一定要「從下拉選單點選」變 chip，不可純文字

- 純文字 @地藏 = 阿美看不到圖 = 靠想像畫 = 會漂移
- 從 @ 下拉選單點選卡片（變 chip / 出現「For Image#N: URL」）= 照著照片畫 = 鎖得準

#### 鐵律二：一張「真的出圖」才送下一張 -- 絕不連送

- 2026-06-04 阿美當機掛掉的根因：阿地連送太多命令把 agent 灌爆
- 正確節奏：選卡 -> 貼場景 -> 送出 -> 等到「真的出圖」-> 才碰下一張
- 她生成中：不要打字、不要選卡、不要預貼下一張

#### 鐵律三：送出後必須「親眼驗到圖」才算完成

- 要看到完整鏈：「讓我生成」->「生成中」->「創作完成」+ 真的多一張圖
- 只看 busy 到 idle 就報完成 = 假完成

### @選卡操作（Enter 快速選卡法）

1. JS `ed.focus()`（不要 left_click 畫布）
2. computer `type` 卡名核心+「完」-> 等1秒 -> `type`「整」
   - 菩薩卡用「@核心完整」唯一命中（例 @地藏完整 / @佛陀完整）
   - 飽和度用「@色彩飽和」+「度」
   - 大眾用「@一般人物風格參」+「考」
3. 等約 4 秒選單跳出 -> computer `key "Return"` 選中第一個
4. JS 讀 `ed.innerText` 確認 chip 進去了

### 畫布點圖選參考（阿元手動快速法）

1. 點畫布上角色卡圖片 -> 圖被選中加進輸入框當 chip
2. 點一下輸入框（焦點移回）-- 不可省！
3. 點下一張角色卡圖片
4. 再點輸入框
5. 重複直到所有卡選完
6. 貼命令文字 -> Enter 送出

清空編輯器時若焦點在畫布，Ctrl+A 加 Delete 會把參考圖全刪！

安全清空方式：`e.click(); e.focus()` -> Ctrl+A -> Delete -> 截圖確認畫布圖還在

### 送出方式

1. chip 後用 JS DataTransfer paste 塞場景文字（角色用純名稱不加@）
2. computer `key "Escape"`（關殘留@選單）-> JS 游標移文末 -> computer `key "Return"`
3. JS 確認 `ed.innerText.length` 回到 1 = 送出成功
4. 等「真的出圖」才做下一張

## 3. 技能三：LoveArt 圖片下載（PS1 + UTF-8 BOM 法）

### 問題根源（已解決）

`download_xxx.bat` 閃退的根因：PowerShell 5.1 對無 BOM 的 PS1 用 ANSI/CP950 解析，中文路徑亂碼，ParserError，立刻退出。

### 唯一正確解法：Python wb 模式寫 PS1，頭部加 BOM

```python
with open("download_xxx.ps1", "wb") as f:
    f.write(b'\xef\xbb\xbf')          # UTF-8 BOM -- 絕對必要！
    f.write(ps1_content.encode('utf-8'))
```

不能用 Write tool 直接寫含中文的 PS1（無 BOM）。
不能用 bash echo/cat 寫（同樣無 BOM）。
只有 Python `f.write(b'\xef\xbb\xbf')` 才保證加 BOM。

### 資料夾結構

```
每篇貼文/
  YYYY-MM-DD_第N篇_品名/
    圖片/
      01_.png ~ 12_.png
```

命名：`NN_.ext`（固定前綴，不加 LoveArt ID）

### 操作 SOP

#### Step 1：取得圖片 URL

從 LoveArt 畫布右鍵複製圖片網址，或從 chat 回覆中抓。

格式：`https://a.lovart.ai/artifacts/agent/[16字元ID].[ext]`

#### Step 2：確認篇號與資料夾

```bash

```

#### Step 3：Python 生成 PS1（含 BOM）

```python
python3 << 'PYEOF'
ps1_content = r"""$ErrorActionPreference = "Continue"
$BASE = "C:\Users\chenj\Documents\Claude\Projects\自動化每天更新FB 地藏 10輪經\每篇貼文"

Write-Host "下載第N篇" -ForegroundColor Cyan
if (-not (Test-Path $BASE)) { Write-Host "ERROR: $BASE 不存在" -ForegroundColor Red; Read-Host; exit 1 }

function DL($url, $out) {
    try { Invoke-WebRequest -Uri $url -OutFile $out -UseBasicParsing -EA Stop; Write-Host "  OK: $(Split-Path $out -Leaf)" -ForegroundColor Green }
    catch { Write-Host "  FAIL: $(Split-Path $out -Leaf) - $_" -ForegroundColor Red }
}
function EnsureDir($path) { if (-not (Test-Path $path)) { New-Item -ItemType Directory -Path $path | Out-Null } }

Write-Host "[第N篇] YYYY-MM-DD_第N篇_品名" -ForegroundColor Yellow
$d = "$BASE\YYYY-MM-DD_第N篇_品名\圖片"
EnsureDir $d
DL "https://a.lovart.ai/artifacts/agent/[ID01].png" "$d\01_.png"
DL "https://a.lovart.ai/artifacts/agent/[ID02].png" "$d\02_.png"
# ... 填12張
DL "https://a.lovart.ai/artifacts/agent/[ID12].png" "$d\12_.png"

Write-Host "完成！" -ForegroundColor Cyan
Read-Host "按 Enter 關閉"
"""

with open("/sessions/.../mnt/自動化每天更新FB 地藏 10輪經/download_第N篇.ps1", "wb") as f:
    f.write(b'\xef\xbb\xbf')
    f.write(ps1_content.encode('utf-8'))
print("PS1 已生成 (含BOM)")
PYEOF
```

## 5. 技能五：AI 連環漫畫角色一致性

### 一頁速查

1. 引擎都是 Nano Banana Pro（= Gemini 3 Pro Image）
2. 鎖角色 = 丟一張好參考圖當錨點（一張大於等於 1024、光線清楚就夠）
3. prompt 用結構化 brief，不要堆關鍵字
4. 要顯示的文字用雙引號鎖定
5. 母版鎖定：每格都參考同一張 8K 母版卡，絕不拿上一張畫下一張（會雪崩漂移）
6. 改圖用 Edit 局部改，不要整張 re-roll
7. 85% 是天花板：每篇預留 15% 修圖，1-2 張需修是正常
8. 服裝比臉難固定，服裝單獨給一張特寫當 ref
9. 參考圖 6 張封頂（不是 14；超過 10 張反而更糟）
10. 比例 1:5-1:7 正常人類，主角靠光暈辨識不靠身高

### 母版鎖定法（2026-06-01 修正，取代舊「滾動參考」）

```
母版 = 8K 高清角色卡
Panel 1: ref = 母版    <- 主錨
Panel 2: ref = 母版    <- 一樣回母版, 不是Panel1
Panel 3: ref = 母版    <- 一樣回母版
...永遠母版
```

舊版教「每格參考前1-2張」是錯的，會誤差雪崩。

### 每格 prompt 固定英文咒語（逐字不變）

```
Keep the character's facial features exactly the same as the reference image.
```

一格只改「一個變數」（場景 or 動作擇一），角色描述逐字不變。

## 附錄 C：DataTransfer paste 終極 SOP

不需 ctrl+v、不搶 Win+H、不點畫布。

```javascript
const editor = document.querySelector('[contenteditable=true]');
editor.focus();
const dt = new DataTransfer();
dt.setData('text/plain', promptText);
const ev = new ClipboardEvent('paste', {
  clipboardData: dt,
  bubbles: true,
  cancelable: true
});
editor.dispatchEvent(ev);
// dispatchEvent 回 false 不是失敗！看 editor.innerText 才準
```

清空編輯器安全法：

```javascript
const e = document.querySelector('[contenteditable=true]');
e.click();    // 確保焦點在文字框
e.focus();    // 雙保險
// 然後才能 Ctrl+A -> Delete
```
