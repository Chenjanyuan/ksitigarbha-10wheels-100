步驟 1：上稿前先清草稿
  navigate 到：
  https://business.facebook.com/latest/posts/drafts/?asset_id=1093357677358320
  把所有草稿手動全刪。或用 Playwright 自動跑「全部刪除」按鈕。

步驟 2：進 composer 後立刻驗證乾淨（必跑這段 JS）
  mcp__playwright__browser_evaluate(function="""
  () => {
    const imgs = Array.from(document.querySelectorAll('img'));
    const drafts = imgs.filter(i => i.src.includes('fbcdn') && i.getBoundingClientRect().x < 400);
    const dirty = !!document.querySelector('button[aria-label*="編輯相片"], button[aria-label*="移除相片"], button[aria-label*="更換圖像"]');
    return { draft_imgs: drafts.length, dirty_buttons: dirty };
  }
  """)

  ★ 若 draft_imgs > 0 或 dirty_buttons = true → 草稿沒清乾淨，不能繼續，回步驟 1。
  ★ 若 draft_imgs = 0 且 dirty_buttons = false → 乾淨，可以繼續。

步驟 3：找正確的按鈕（重點）
  ❌ 不要點：「附加相片或影片」（single file，上不了 12 張）
  ✅ 要點：「新增相片 / 影片」（multiple file，這個才行）
  從 snapshot grep "新增相片" 找 ref，不是 "附加相片"。

步驟 4：browser_file_upload 直接給 Windows 絕對路徑
  paths=[
    "C:\\Users\\chenj\\Documents\\Claude\\Projects\\自動化每天更新FB 地藏 10輪經\\每篇貼文\\YYYY-MM-DD_第N篇_品名\\圖片\\01_xxx.png",
    ...12 張...
  ]
  Playwright MCP 本機跑（cmd /c npx -y），不在沙箱裡，能讀 Windows 檔案系統。
  不用試什麼 temp 目錄，原路徑就行。

其他 3 個誤判細節（順便修一下觀念）
═══════════════════════════════════════

▸ browser_evaluate 在 modal 開啟時被阻擋 = 設計正確，不是 bug

  要在 click「新增相片」之前先掛 listener，不是之後。
  但其實 browser_file_upload 內部已經處理好，你不用自己掛 waitForEvent。

▸ 「沙箱無法存取用戶文件」= 你跑的是雲端 sandbox 不是本機
  Playwright MCP 是阿元本機裝的（cmd /c npx -y），跑在 Windows 上能直接讀
  C:\Users\chenj\... 路徑。你如果看到「No such file or directory」，
  是因為你用 Python 在 cowork sandbox 跑，不是 Playwright MCP 跑。
  改用 mcp__playwright__browser_file_upload 直接給 Windows 路徑就行。
