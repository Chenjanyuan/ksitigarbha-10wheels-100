# 第 11 章 — 緊急排錯表(常見 20 雷)

## 11.1 LoveArt 相關

| 症狀 | 原因 | 解法 |
|------|------|------|
| editor paste 後 length=1 | React 忽略 paste event | 改用 `chrome computer.type` 直接 type |
| 阿美 5+ 分鐘沒回應 | 卡住 silent block | `window.location.reload()` 一次 |
| 連續送觸 CAPTCHA | LoveArt 偵測 bot | 一張一張送,等阿元勾 hCaptcha |
| 角色臉漂移 | 純文字 @ 沒鎖到 | 必須點 dropdown 變 chip |
| 12 張頁碼不一致 | batch 5 / 12 張不穩 | 一張一張送 + 親眼驗圖 |
| dropdown 沒「人物參考-4/-5」 | 順序隨用過變動 | 用 JS find by text 替代座標 click |
| 畫布所有圖被刪 | Ctrl+A 焦點跑畫布 | 用 JS execCommand('delete') |
| 篇 N 命令貼錯到別篇 | editor 沒清空 | 先 `ed.querySelectorAll().remove()` |

## 11.2 Meta 上稿相關

| 症狀 | 原因 | 解法 |
|------|------|------|
| file_upload 回 undefined | React state 沒就緒 | poll 法等 5 秒 |
| 12 張字母序排亂 | 檔名「12之X」干擾 | 改 `pianN_NN.jpg` 0padded |
| 套用全部 switch click 沒生效 | React-controlled | 驗 `aria-checked=true`,沒開再 click |
| 推銷 dialog 擋住 | Meta 升級提示 | poll 找有就點「以後」 |
| 排程時間沒設到 | 點到「立即發布」 | 先點「排程」鈕再選時間 |
| 編輯相片按鈕找不到 | zero-width space 字元 | 用 `includes` match(不 filter size) |
| 排版擠 / 空行多 | composer paste 邏輯 | dump innerText + max_blank_run=2 |
| Token 過期 | 60 天到期 | 用 UI 不靠 Graph API |

## 11.3 系統 / 沙箱相關

| 症狀 | 原因 | 解法 |
|------|------|------|
| chrome MCP tab 不見了 | 對話切換 / chrome 重啟 | `tabs_context_mcp({createIfEmpty: true})` |
| 沙箱 curl LoveArt 403 | CDN 認 Referer | 在阿元電腦跑 .bat |
| docx cp 變 0 byte | 沙箱 bug | `git cat-file -p HEAD:路徑` |
| PowerShell 中文 ParserError | ANSI 編碼 | .ps1 存 UTF-8 BOM |
| .bat 雙擊閃過 | 結尾 pause 被誤按 | 用 `cmd /k` 永不關 |
| GitHub force push 500 | repo 2.57 GB 太大 | 用 push_jizang.bat 普通 push |
| index.lock 卡死 | 沙箱 git 異常 | `mv .git/index.lock .git/index.lock.bak` |
| Win+H 中文輸入被搶 | type 操作干擾 | JS paste 不搶 / 分時段 |
| chrome hidden visibilityState | 鎖屏/最小化 | chrome 保持前景可見 |
| MCP server disconnected | 連線中斷 | 等系統 reconnect / `ToolSearch` |

```

📊 當前進度 (yyyy-mm-dd):
- 連載:篇 N 已發布 / 篇 N+1 已排程 / 篇 N+2 待做

⛔ 死命令 1-15 已確認(寶冠漢傳 / 9 環錫杖 / 1:5-1:7 / 繁體 / 不漂移 / 純淨檔名 / 1:1套用)

下一步 4 選 1:
A. 確認篇 N 已下載 → 開始篇 N+1
B. 用 API daemon 衝量篇 N~N+10
C. 補寫某篇 docx(內文+啟發反思+圖片計畫)
D. 其他指示
```

## 12.5 ⚠️ 絕對遵守

- ✅ 看到咒語 → **立刻動作**,不囉嗦
- ✅ 真的去讀檔案,不是假裝記得
- ✅ 4 個核心檔都讀,不要省略
- ❌ 不可說「我記得」就跳過
- ❌ 不可只讀一個檔案
- ❌ 不可改編固定報告格式

## 12.6 為什麼這樣設計

阿地在跨對話 / 壓縮後會失憶,假裝記得會出錯。用「魔法咒語」做 fail-safe — 一個關鍵詞就 100% 救回。比每次重新解釋 5 AI 大會結論 + 6 模板 + 100 篇官方鎖定快太多倍。

## 12.7 連動情境(沒講咒語但有相關)

阿元講:
- 「我們繼續做地藏」
- 「來做篇 N」
- 「衝下一張」
- 「100 篇下一篇」

→ 主動確認:「阿地 確認:100 篇官方鎖定地藏寶冠版 + 9 環錫杖,用 v8 模板。對嗎?」
→ 阿元說對 → 動手
→ 阿元說錯/有變 → 觸發完整恢復流程
