## 🎯 核心觀念 — 為什麼會「失憶」?

你 (Claude) 跟 user 對話到一個程度, 系統會**自動壓縮 context**:
- 舊對話被收進 summary, 你只記得**摘要**, 不記得**細節**
- 工具呼叫的中間結果消失
- 之前生成過的內容變模糊
- **但檔案系統還在!** 寫到磁碟的東西**不會跟著被壓縮**

★ 反過來說 — 只要把當下狀態**及時釘進檔案**, 壓縮就傷不到你

---

## 🧰 三件套 (壓縮後立刻做)

不管壓縮多嚴重, 開頭做這三件事就能秒回神 (大約 1 分鐘):

### 1. 對時 (★ 鐵則)

```bash
TZ='Asia/Taipei' date '+%Y-%m-%d %H:%M (%A 週%u)'
```

(換你的時區, 例: `TZ='UTC'` / `TZ='America/New_York'`)

不憑記憶猜時間 — 系統有真實時鐘。

### 2. 讀 user 的工作 SOP + 即時續班快照

按順序讀:
1. **CLAUDE.md** (專案根目錄, project 最高優先級規則)
2. **MEMORY.md** (你的 auto-memory 索引)
3. **★即時續班快照** (最關鍵 — 等下教你寫)
4. **交接 SOP** (如果有 v3/v4)

### 3. 看當下實時狀態

如果工作涉及 UI (LoveArt、Web App、Slack 等):
- 截圖看當下狀態
- 用 JS / API 抓真實資料 (不要相信 panel 顯示的進度 — 可能是幻覺)

## 📝 即時續班快照 (核心武器)

每次完成關鍵節點就**更新覆蓋**一份檔案, 就叫:

```

```

放在 `<project>/阿地交接/` 或任何固定位置。下次壓縮後, 你 (或下一位 Cowork 同事) 第一件事就是讀這份。

## ⚡ 更新時機 (什麼時候覆蓋這份檔)

每次發生以下事件就**覆蓋這份檔案**:

1. ✅ 完成一個關鍵節點 (例: 一批圖完成, 一個 feature merge)
2. ⚠️ 使用者拍板新規矩 (例: 「以後 max 6 張」)
3. 🚨 發現重大問題 (例: panel 顯示是幻覺, 實際狀況不一樣)
4. 🔄 工具設定改變 (例: 換 Chrome tab, 換按鈕座標)
5. ❓ 卡住 / 等使用者回覆

**檔名**: 用 `★即時續班快照_YYYY-MM-DD_HH-MM.md` 帶時間戳, 舊版可保留作歷史或直接覆蓋

## 🧪 memory 系統怎麼用 (進階)

Claude 的 auto-memory 在:
```
C:\Users\<USER>\AppData\Roaming\Claude\local-agent-mode-sessions\<...>\spaces\<...>\memory\
```

(Windows; 其他系統位置不同)

裡面 `MEMORY.md` 是索引 (每次對話 auto-load 前 200 行), 其他 `*.md` 是分類記憶檔。

★ 不同 cowork session 的 memory 是**獨立的**, 阿狗 不會看到 阿地 的 memory。所以:
- 通用 SOP (像本檔) 放 **project 資料夾** (跨 session 共用)
- 個人化記憶 (像 user 暱稱、口頭禪) 放 **memory 系統** (該 session 私有)
