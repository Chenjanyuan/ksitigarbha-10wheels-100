## ★★★ 2026-05-19 阿元拍板的 5 大新規範

### 規範 1:對時鐵則(每次對話開頭必做)

```bash
TZ='Asia/Taipei' date '+%Y-%m-%d %H:%M (%A 週%u)'
```

不憑記憶猜時間,用 bash 抓真實系統時鐘 + 強制台北時區。

### 規範 2:LoveArt 黃金時段(00:00~08:00)

★ 半夜 12 點到早上 8 點,LoveArt 人最少, 阿美算圖最快(可能 0 排隊)
★ 對時後第一個判斷就是「是不是黃金時段?」
★ 是 → 全力推進, 一張接一張
★ 否 → 提醒阿元晚上 12 點後再衝

### 規範 3:標準生成命令 SOP(完整存在 memory)

每張腳本 = 故事內容 + 死命令清單 + 完整角色卡塊(9 菩薩+大眾)+ 風格鎖定 URL

詳見 `memory/feedback_standard_script_sop.md`

### 規範 4:一張一張做、一張一張存

**鐵則** — 不要批次生再批次撈!

```
1. 寫腳本 → 送 LoveArt
2. 等阿美畫
3. 我親自檢查 10 項死命令
4. 不對 → 重出, 直到全 ✅
5. 通過 → ★ 立刻下載到對應日期資料夾
6. 再開始下一張
```

### 規範 5:存檔名稱格式

`MMDD-第N篇-照片-NN-故事簡略.png`

範例:
- `0519-第一篇-照片-01-佉羅帝耶山.png`
- `0528-第八篇-照片-11-啟發反思.png`

每張腳本要把這格式明寫在【存檔名稱】欄位,阿美命名 + 阿地下載時都用這格式
