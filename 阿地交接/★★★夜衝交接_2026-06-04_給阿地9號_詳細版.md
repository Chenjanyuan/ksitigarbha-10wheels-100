## 2. ★ @選卡 穩定操作（Enter 快速選卡法，2026-06-04 驗證最穩）
**比用座標點穩超多**（座標點常因清單上下位移點到錯的分鏡圖）：
1. JS `ed.focus()`（不要 left_click 畫布）。
2. **分段打卡名**：computer `type` 卡名核心＋「完」→ 等 1 秒 → `type`「整」。
   - 菩薩卡用「**@核心完整**」唯一命中、跳過同名分鏡圖（@地藏完整／@佛陀完整／@文殊完整）。
   - 飽和度＝「@色彩飽和」+「度」；大眾＝「@一般人物風格參」+「考」。
   - ⚠️ **debounce**：第一次常只跳「最近3筆」沒過濾 → **分段打、最後一字當觸發**逼它重比對。
3. 等 ~4 秒選單跳出、第一個是要的卡 → computer `key "Return"`：
   - ★★ **選單開著時 Return ＝ 直接選中第一個變 chip，不是送出！**
4. JS 讀 `ed.innerText` 確認 chip 進去了（出現「For Image #N: URL」）；沒進就重來別硬幹。
5. 該格所有卡都點齊（地藏／佛陀／色彩飽和度／一般人物…）。

### 貼場景 → 送出
1. chip 後面用 JS `DataTransfer paste` 把場景整段塞進去（場景裡角色用**純名稱、不要再加 @**，免得又跳選單）。
2. computer `key "Escape"`（關殘留 @ 選單）→ JS 游標移到文末（selectNodeContents+collapse(false)）→ computer `key "Return"`（送出）。
3. JS 確認 `ed.innerText.length` 回到 1 ＝ 輸入框清空＝送出完成。
   - ⚠️ 清空輸入框要用 **JS全選 → computer key "Delete"**（`innerHTML=''` 對React無效、會疊加）。
4. **接著進鐵律三：等「真的出圖」才做下一張。**

先對台北時間(bash `TZ='Asia/Taipei' date`；黃金時段00:00-08:00)。請阿元開阿美媽媽分頁→你接上→reload→**選卡成chip(Enter法)→貼場景→Escape→游標末→Return送出→等真出圖→才下一張**，按缺圖表補圖、逐張驗收。**寧可慢，一張一張、出圖才下一張，阿美就不會再掛。** 要阿元決定的找阿傳。畫布跟記憶都保存好了，安心接力 🌸💪🙏
