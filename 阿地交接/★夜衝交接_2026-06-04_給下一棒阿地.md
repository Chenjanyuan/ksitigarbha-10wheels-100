## 1. 每張圖「送出」標準步驟（★實證穩定，務必照做）
LoveArt 輸入框是 React/Lexical，**JS focus+button.click 送不出**，必須真實鍵盤。
```
1. JS: ed=document.querySelector('[contenteditable="true"]'); ed.focus();
       DataTransfer paste 該格「—— 貼入 ——」整段(含@提及當文字一起貼).
2. computer key "Escape"   ← ★關掉@提及彈窗! prompt含@會跳選單(顯示No results found)攔截Return,不按Escape會送不出.
3. JS: ed.focus(); 用 selectNodeContents+collapse(false) 把游標移到文末.
4. computer key "Return"   ← CDP真實鍵=送出.
5. JS: 檢查 ed.innerText.length===1 ＝ 送出成功(輸入框清空).
   若還有字：再 Escape → 游標移末 → Return（@選單可能還開著）.
```
### 清空輸入框（要重貼時）
- ⛔ `ed.innerHTML=''` 對 React 編輯器**無效**（會變兩段疊加、len 爆增）。
- ✅ 正解：JS `selectNodeContents` 全選 → **computer key "Delete"** → len 回 1。

### 卡住 / 太慢
- 計時 >5min 或一直「生成中/排队中」：按**停止鈕**（輸入框右下紅色■，座標約 (1361,837)，或 JS 找含「停止」的鈕）→ 取消 → 阿美空閒 → 重送。**停止鈕實證有效！**
- 想跳隊：點「**立即生成，仅需⚡8积分**」（JS 找含「立即生成」葉節點 click）。⚠️ 一張 8 點，剩 ~340 點 ≈ 只夠 42 張，別每張都跳。阿元說免費掛著等就好。
- **reload 只用一次別連續**（會把卡死 job 重新排隊；reload 後免費 job 會接著重跑）。
