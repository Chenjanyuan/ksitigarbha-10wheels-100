## 4. 核心操作 SOP

### ⛔ 阿美 卡住 → reload (2026-05-29 阿元 拍板)

```
阿美 5+ 分鐘無回應 → window.location.reload() → 等 10 秒 → 重新 paste + Enter
```
不可連續 reload, 觸 CAPTCHA 等阿元 勾.

### 每張 send 流程 ★ 2026-05-29 阿地 5 號 拍板 — 必用 Enter Key!

```
Step 1: 等阿美 「思考中」消失 (上一張完成)
Step 2: JS DataTransfer paste prompt → editor 有內容
Step 3: JS editor.focus()
Step 4: chrome computer.key "Return"  ← Enter 觸發 send (CDP 真實 keystroke, isTrusted=true)
Step 5: wait 3-5 秒
Step 6: JS check editor.innerText.length === 1 = 送出成功
Step 7: JS check thinking=true = 阿美 開始畫
```

⛔ **絕對禁止用 send button click!** 詳見 CLAUDE.md 死命令 0.
- ❌ JS sendBtn.click() → 觸 CAPTCHA
- ❌ chrome left_click [send] → 不生效
- ✅ chrome computer.key "Return" → 100% 成功且安全

### Editor 座標 inspect (每張必查!)
```javascript
const editor = document.querySelector('[contenteditable=true]');
const er = editor.getBoundingClientRect();
const editor_x = Math.round(er.x + er.width/2);  // 通常 638 或 1281
const editor_y = Math.round(er.y + er.height/2);  // 通常 734 或 729
```

### Send button 取得 (每張必抓!)
```javascript
const btns = Array.from(document.querySelectorAll('button'));
const sendBtn = btns.find(b => 
  b.className.includes('rounded-full') && 
  b.className.includes('h-8') && 
  !b.disabled
);
sendBtn.click();
```

### 等阿美 完成
```javascript
// 「思考中」消失 = 阿美 完成 = 可送下一張
({thinking: document.body.innerText.includes('思考中')})
```

## 9. 失敗教訓

### 9-5 巨人化 (2026-05-26)
**錯**: 主角段 (第 3 段) 跟對白段 (第 8 段) 不一致 → 阿美 邏輯衝突 → 把地藏拉超大
**對**: 第 3 段必須含對白會出現的所有主角

### 9-4 飽和度跑掉 (2026-05-27)
**錯**: 只寫「飽和度」3 字 (40% 準確率)
**對**: 寫「色調+飽和度+明亮度+光感 4 維度」(95% 準確率)

### Send 點 2 次 = cancel
**錯**: 看 editor 沒清空就再點
**對**: 點 1 次後等 5 秒 → 看 thinking=true 確認, 不點第 2 次

### Lexical \n 截斷
**錯**: prompt 內含 \n, Lexical 第一個 \n 觸發 send → 後面內容被截掉
**對**: 一行式 prompt (空格分隔)

### Chrome computer left_click [send] 不穩
**錯**: 用 chrome computer left_click [1448, 791] → 有時不生效
**對**: 用 `JS sendBtn.click()` 直接呼叫 button 內建方法 → 100% 可靠

### DataTransfer paste 觸發 CAPTCHA
**錯**: 用 JS DataTransfer ClipboardEvent → isTrusted=false → LoveArt 跳 hCaptcha
**對**: 用 **CDP type** (chrome computer type) → isTrusted=true → 不觸 CAPTCHA

### Editor 座標每次不同
**錯**: 假設 editor 在固定位置
**對**: 每張前 JS inspect editor.getBoundingClientRect() 取最新中心點
