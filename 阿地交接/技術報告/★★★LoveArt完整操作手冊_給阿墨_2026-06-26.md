## 1. 血淚提醒

⛔⛔⛔ **LoveArt 畫布絕不可寫文字 / 絕不可 Ctrl+A 全選**(阿元 2026-06-26 二度強調)

| ❌ 危險 | ✅ 安全替代 |
|--------|-----------|
| `chrome computer key "ctrl+a"`(可能擴到畫布) | JS `range.selectNodeContents(ed)` 只選 editor 內 |
| `chrome computer key "Delete"` 在 editor 空時 | JS `document.execCommand('delete')` |
| `left_click` 猜座標(editor 浮動) | JS `querySelector` 抓 editor 後 `.focus()` |
| 看到「文字工具(T)」icon 亮 | 馬上 Escape 退出 |

**type 命令前 7 步驗證**:
```
1. JS focus editor + verify activeElement === ed
2. JS dump editor.innerText.length(應 ≤ 1 表示空)
3. JS dump editor 內的 chips
4. 截圖確認 editor 有 placeholder 'Start with an idea'
5. 才用 chrome computer.type 打字
6. type 後再 dump editor.innerText.length(應 > 300)
7. 截圖確認畫布上沒多出文字物件
```

## 2. 手動操作 SOP — loveart-amei-card-command 全文

> 來源:`anthropic-skills:loveart-amei-card-command/SKILL.md`(2026-06-15 阿元親授完整版)

### 三大血淚鐵律

**鐵律一**:角色卡一定要「從下拉選單點選」變 chip,不可純文字。純文字=想像,點選卡片=照片。

**鐵律二**:一張「真的出圖」才送下一張。絕不連送、絕不預貼,她運算中完全不動框。連送會把 agent 灌爆過載當機。

**鐵律三**:送出後必須「親眼驗到圖」才算完成。要看到完整鏈:阿美回「讓我生成」→ 進度條 →「創作完成」+ 真的多一張頁碼 N/12 的圖。三者齊才算。busy/idle 不算。

### 黃金時段

- 阿美免費佇列:台北 00:00–08:00 最快最穩(~2-3 分/張);08:00 後全球塞車。大量補圖排夜衝。
- 寧可慢、不可連送。一張出圖才下一張。穩 > 快。

### 前置:先在 LoveArt 建好「卡」

1. 每個角色一張「完整角色卡_12格」(12 宮格定裝)
2. `色彩飽和度參考` 一張(鎖鮮豔,每格必 @,漏了變淡)
3. `一般人物風格參考-1/-3` 等多張輪流

### @選卡 Enter 快速選卡法

```
1. JS ed.focus()(不要 left_click 畫布)
2. computer type 卡名核心+「完」→ 等 1 秒 → type「整」
   - 用「@核心完整」唯一命中卡(例 @地藏完整/@佛陀完整)
   - debounce:第一次常只顯示「最近 3 筆」沒過濾 → 分段打、最後一字當觸發
3. 等 ~4 秒選單跳出、第一個是要的卡 → computer key "Return"
   (選單開著時 Return = 選第一個變 chip,不是送出)
4. JS 讀 ed.innerText 確認 chip 名稱進去了;沒進就重來
5. 該格所有卡都點齊(角色/色彩飽和度/一般人物)
```

### 畫布點圖選參考(阿元手動快速法)

比 @打字法快很多。畫布上已有的角色卡可直接點選當 chip 參考。

```
1. 點畫布上第1張角色卡圖片(例:色彩飽和度參考)
   → 圖被選中(藍框工具列)= 已加進輸入框當 chip
2. 點一下輸入框(chip 後面的空白處)
   → 焦點移回文字框。這步不可省!
3. 點畫布上第2張角色卡圖片
   → 第2個 chip 加入
4. 再點一下輸入框
5. 如果還有第3張,重複 3→4
6. 貼命令文字(Ctrl+V)
7. 按 Enter 送出
```

⛔ **死命令:絕對不可刪畫布參考圖**(2026-06-15 阿元二度強調)

清空輸入框時,若焦點停在「畫布」而非「文字框」,Ctrl+A → Delete 會把畫布上的參考圖全部刪掉!

**安全清空 SOP**:
```
① 先 JS: e.click(); e.focus()  ← 確保焦點在「文字框」
② 再 Ctrl+A → Delete
③ 清空後截圖確認:畫布左側參考圖還在才繼續!
```

### 送出與等待(自動化通用)

```
1. chip 後面用 JS DataTransfer paste 把場景整段塞進去
   (場景裡角色用純名稱、不要再加 @)
2. computer key "Escape"(關殘留 @ 選單)
   → JS 游標移到文末
   → computer key "Return"(送出)
3. JS 確認 ed.innerText.length 回到 1 = 輸入框清空 = 送出完成
4. 等「真的出圖」。出圖了才下一張。
```

### 每格 prompt 結構

```
[已點選的角色卡 chip:地藏/佛陀/色彩飽和度/一般人物]
🎨 場景(中景/廣角, 吉卜力電影分鏡感):[角色位置(純名稱)] + 背景 + 光影
💭 旁白方框(左上, 淺黃底, 繁體):「……」
🗣️ 對話氣泡(圓潤泡, 繁體白話, 小三懂):角色(情緒):「……」
📌 頁碼:右下角白圓黑字 N/總
✅ 色彩飽和度參考鎖定 + 吉卜力 Studio Ghibli 天空之城 2D 動畫水彩風 + 高飽和度鮮豔 + 水粉質感 + 丁達爾光
   + [該角色官方造型死命令] + 成人1:5-1:7比例(不巨人) + 全繁體無簡體無錯字 + 1:1正方形2K無邊框。只生成這一張。
```

- 對話氣泡只寫「角色(情緒):『話』」,不寫服飾(服飾寫場景段)
- 角色官方造型死命令:地藏=漢式五佛冠+九環錫杖+土黃袈裟+圓臉淡金膚;佛陀=螺髮肉髻非腫瘤+白毫+橙袈裟;觀音=漢傳華麗天冠冠中阿彌陀佛化佛

### 卡住/當機排除

| 症狀 | 處理 |

## 4. 下載圖片 — loveart-download-skill 全文

### 問題根源

`download_xxx.bat` 閃退不執行的根本原因:**PowerShell 5.1 對無 BOM 的 PS1 檔用 ANSI/CP950 解析 → 中文路徑亂碼 → 第一行就 ParserError → 腳本立刻退出**

### 唯一正確解法

用 bash Python 寫 PS1,在頭部加 UTF-8 BOM bytes (`\xef\xbb\xbf`):

```python
with open("download_xxx.ps1", "wb") as f:
    f.write(b'\xef\xbb\xbf')          # UTF-8 BOM — 絕對必要!
    f.write(ps1_content.encode('utf-8'))
```

- ❌ 不能用 Write tool 直接寫含中文的 PS1(Write tool 輸出無 BOM UTF-8)
- ❌ 不能用 bash echo/cat 寫(同樣無 BOM)
- ✅ 只有 Python `f.write(b'\xef\xbb\xbf')` 才保證加 BOM

### 命名規則

- `01_.png` ~ `12_.png`(固定前綴 `NN_`,後面不加 LoveArt ID)
- 副檔名跟 LoveArt 原檔一致(`.png` 或 `.jpg`)
- 第 11 張固定為「啟發反思」,第 12 張固定為「索取本願經」

### 操作 SOP

1. 取得圖片 URL(LoveArt 畫布右鍵複製、生成歷史、chat 回覆)
2. 確認篇號與資料夾名稱:`ls 每篇貼文/ | grep "第N篇"`
3. 用 Python 生成 PS1(含 BOM)
4. 生成對應的 .bat 啟動器(用 Write tool 即可)
5. 驗證下載結果:`ls -la "$dir"` 確認 12 個檔案,每個 >500KB

### 鐵則總結

1. PS1 含中文路徑 → 一定要 BOM → 一定用 Python wb 模式寫
2. bat 結尾一定要 `pause`(否則視窗閃退看不到錯誤)
3. LoveArt 圖片 URL 7天內有效,生完立刻下載
4. 下載後用 `ls -la` 確認 12 個檔案且各 >500KB
5. 沙箱無法直接下載 LoveArt 圖(403)→ 只能生 PS1 讓阿元在 Windows 跑

### 必加 Header

```
Referer: https://www.lovart.ai/   ← 沒這行 403
User-Agent: Mozilla/5.0 ... Chrome/130.0.0.0
```

## 5. 阿地實戰經驗

### 5.1 與阿元的分工(2026-06-26 阿元拍板)

**阿地**:
- 用 `chrome computer.type` 把命令文字 type 進 editor
- type 後 dump 驗證 `innerText.length > 300`

**阿元**:
- 手動選人物 chip(他自己點選比阿地座標 click 準確)
- 按 Return 送出

★ 這分工避免阿地點錯 chip(座標漂移),阿元手動選最穩。

### 5.2 chrome MCP tab 中斷救法

症狀:阿元中途切 tab、Claude 重連,tabs_context_mcp 回 `No tab group exists`

救法:
```javascript
tabs_context_mcp({createIfEmpty: true})
navigate(LoveArt URL, newTabId)
wait(6)
```

### 5.3 paste 失敗備案

症狀:DataTransfer paste event 進去後 `innerText.length === 1`(React 忽略)

備案:改用 `chrome computer.type` 直接打字(中文慢但永遠成功)

### 5.4 type 後 editor 變空

症狀:type 完命令進去,過幾分鐘 editor 又空了

原因:阿元另一個對話切走、或 chrome 重 render

救法:重新 type 一次。每次 type 前先 `dump editor.innerText.length` 確認。

### 5.5 重出版的構圖變化技巧

當阿美對同一場景重出時,要強調換構圖:
- 第一次:正面平視 → 重出:低角度仰拍(突顯主角神聖感)
- 第一次:廣角全景 → 重出:特寫近景(強調情緒)
- 第一次:右側角度 → 重出:左側鏡像(換視角)

命令裡加:「★★★ 本張是「重出版」,構圖請與上一次完全不同(換角度、換布局、換視角)!」

### 5.6 上稿期間的工作流

阿元 LoveArt 邊操作邊上稿時的最佳節奏:
1. 阿地 type 篇 N 之 X 命令 → editor
2. 阿元加 chip + Return
3. 阿美生圖約 2 分鐘
4. 阿元說「繼續」→ 阿地 type 下一張命令
5. 同時 Meta Business Suite 那邊 paste 貼文文字、上傳圖、1:1 套用、排程

★ 阿元一人多工,阿地不可催、不可預送,只在阿元說「繼續」時動手。

### 5.7 死命令 -1 阿美卡住 reload

症狀:editor 已送(清空),但 chat 5+ 分鐘無新回應

救法:
```javascript

// 重 type 命令 + Enter
```

★ Reload 一次為限(不連續,會觸 CAPTCHA)
