## ⛔⛔⛔ 死命令(違反 = 災難 = 阿元手動救圖)

LoveArt 畫布(canvas)區是放**已生成圖片 + 角色卡參考圖**的地方。
**永遠不可以**:
1. 在畫布上用 `chrome computer.type` 打字 → 會在畫布建立**文字物件**
2. 在畫布上用 `Ctrl+A` 全選 → **選到所有圖**
3. 在畫布全選狀態按 `Delete/Backspace` → **所有圖全被刪!**

## ✅ 正確 SOP(代替危險操作)

### 清空 editor(✅ 用 JS,不用 chrome 鍵盤)
```javascript
const ed = document.querySelector('[contenteditable="true"]');
ed.focus();   // ★ 先確保焦點在 editor
ed.click();   // ★ 雙重保險
// 全選 editor 內容(不會擴到畫布)
const range = document.createRange();
range.selectNodeContents(ed);
const sel = window.getSelection();
sel.removeAllRanges();
sel.addRange(range);
// 刪除
document.execCommand('delete', false);
```

### 找 editor 座標(✅ 用 placeholder text 抓)
```javascript
// 用 querySelector 而不是猜座標
const ed = document.querySelector('[contenteditable="true"][role="combobox"]');
// 或包含特定 placeholder
const ed2 = document.querySelector('[data-placeholder*="Start with"]');
```

### type 命令前的驗證(✅ 焦點確認)
```javascript
const ed = document.querySelector('[contenteditable="true"]');
ed.focus();
// 驗證焦點在 editor
console.assert(document.activeElement === ed, '焦點不在 editor!絕不可 type!');
// 通過才用 chrome computer.type
```

## ⛔ 絕對禁止的操作

| ❌ 危險 | ✅ 安全替代 |
|--------|-----------|
| `chrome computer key "ctrl+a"` | JS `range.selectNodeContents(ed)` |
| `chrome computer key "Delete"`(在 editor 空白時) | JS `document.execCommand('delete')` |
| `left_click` 用猜的座標(editor 浮動位置) | JS `querySelector` 抓 editor 後 `.focus()` |
| 看到「文字工具(T)」icon 亮起 | 馬上 `document.dispatchEvent(new KeyboardEvent('keydown',{key:'Escape'}))` 退出 |
