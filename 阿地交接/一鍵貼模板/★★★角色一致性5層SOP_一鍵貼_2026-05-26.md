# 🪷 角色一致性 5 層 SOP — 一鍵貼版

> **2026-05-26 阿地 整理** | 100 篇通用 | 解決「同篇 12 張內主角變臉變服裝」問題

---

## ⚡ 阿美 真話 (絕對誠實)
> 「AI 無法 100% 同臉. 12 張一次送 = 70-80% 一致. 1 張一張送 = 85-95% 一致.」

→ 100% 不可能, 但用以下 5 層可達 **85-95% 一致**.

---

## 🛡 5 層預防

| 層 | 措施 | 防什麼 |
|---|---|---|
| 1️⃣ | **官方鎖定 URL** (100 篇都同 URL) | 跨篇變臉 |
| 2️⃣ | **URL + Image # 雙重保險** | URL fetch 失敗時的備援 |
| 3️⃣ | **強制特徵清單** (每部位都寫) | 阿美 漏特徵 |
| 4️⃣ | **「禁」清單** (堵錯誤造型) | 阿美 自由發揮錯 |
| 5️⃣ | **1 張一張送** (不批次) | batch 內 context 換人 |

## 🔄 1 張一張送 SOP (重要工程方法)

```
❌ 不要: 12 張一次 batch 送 → 阿美 內部 context 換人 → 70-80% 一致
✅ 改用: 1 張一張送, 等阿美 出完再送下一張 → 阿美 還記得上張 → 85-95% 一致

主身阿地 流程:
1. 送 N-01 prompt → 等阿美 完成
2. screenshot 看圖 → 親眼驗角色長相
3. 通過 → 送 N-02 (預貼 + click send)
4. 失敗 → 重出 N-01 (補強 prompt)
5. 重複到 N-12

⚠️ 預貼 N+1 時, editor 可以放下一張內容, 但不可 click send (會 cancel N!)
   等 N 完成出現新圖 → click send 才送出 N+1
```

## 🛠 如果還是變臉 (4 層補救)

### 補救 1: 重出該張
重新送 prompt, 強調「跟前一張同臉」

### 補救 2: LoveArt edit 法 (10-03 試過, 一致性最好!)
不用「重新生」, 用 LoveArt 的「edit」功能 — 基於前一張改

### 補救 3: 截圖前一張上傳
1. screenshot 前一張地藏特寫
2. 上傳給 阿美
3. 寫: 「這張地藏要 100% 跟這張同臉」

### 補救 4: 直接命令
```
請看上一張 N-01 的地藏長相 (五佛冠+白頭巾+圓臉+黃褐袈裟+九環錫杖),
這張 N-02 必須 100% 同臉同造型, 只改動作/表情, 不可變臉變服飾.
```
