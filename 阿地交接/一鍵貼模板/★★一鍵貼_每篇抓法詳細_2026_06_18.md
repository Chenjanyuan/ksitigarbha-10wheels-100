### Step 10:dispatch paste FB 文字(死命令 2)

★ ⛔ **絕不用 `navigator.clipboard.writeText` + Ctrl+V**!
- Windows clipboard 全系統共享,阿元同時 Ctrl+C 會蓋掉你的文字
- 2026-06-17 阿地 1 號中槍:篇 1 內容變阿海對話,被迫刪除重排

★ ✅ 用 dispatch ClipboardEvent + DataTransfer:

```js
// POST_TEXT = 從 Step 2 讀的 .txt 全部內容
const editor = document.querySelector('[contenteditable="true"][role="textbox"]');
editor.focus();

const dt = new DataTransfer();
dt.setData('text/plain', POST_TEXT);
editor.dispatchEvent(new ClipboardEvent('paste', {
  clipboardData: dt, bubbles: true, cancelable: true
}));
```

★ 驗證:截圖看 composer 文字欄位顯示完整 FB 文,字數 >1500。
