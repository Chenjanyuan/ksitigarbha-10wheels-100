## 🛠️ LoveArt 操作技巧 (重要!)

### Tab 與按鈕
- LoveArt Tab ID: **2141539403**
- 輸入框: contenteditable DIV, 位於 (1250, 720)
- Send 按鈕: 座標 **(1444, 789)** ✅ 用座標 click 比 JS click 更穩

### 長 prompt 送出法 (1000+ 字)
1. ❌ `execCommand insertText` 對長文失效 (回 true 但只進 1 字)
2. ✅ **clipboard 法**:
   ```javascript
   (async () => {
     await navigator.clipboard.writeText(text);
     // 然後 ctrl+v
   })();
   ```
3. ✅ 流程: click editor focus → ctrl+a → Delete → 寫 clipboard → ctrl+v → 等 2 秒 → click (1444, 789) 送出
