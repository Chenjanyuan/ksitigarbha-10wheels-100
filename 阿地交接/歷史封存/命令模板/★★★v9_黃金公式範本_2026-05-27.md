```
1. JS get editor + send 座標 (每張前必查, 因 chat 區會 reflow)
2. chrome computer left_click [editor x, y]  ← focus editor
3. chrome computer type [v9 prompt]  ← CDP type (isTrusted=true)
4. JS editor.focus()  ← ★ send 前必加, 否則 click 不接受
5. chrome computer left_click [send x, y]  ← CDP click
6. wait 5 秒 → JS check editor_len=0 + thinking=true → 確認送出
```
