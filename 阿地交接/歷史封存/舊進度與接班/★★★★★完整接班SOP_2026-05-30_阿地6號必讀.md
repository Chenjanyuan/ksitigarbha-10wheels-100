## 5. Daemon 系統說明

### 檔案位置
```
專案根/
├── daemon.py            ← Python 常駐 daemon
├── start_daemon.bat     ← 阿元 雙擊一次啟動
├── gemini.txt           ← API key (在 .gitignore)
├── _queue/              ← 我寫 task json, daemon 自動讀
├── _done/               ← 完成的 task json
└── _API生圖_2026-05-29/ ← 圖片輸出
    └── 篇XX/
        └── X-NN.png
```

### Task JSON 格式
```json
{
  "out": "篇08/8-05.png",
  "prompt": "Studio Ghibli style... [Scene]... [Text 繁體]...",
  "ref_images": ["篇08/8-05_地藏到佛前住.png"]
}
```

### 使用方式

**阿元 操作 (一次性)**:
1. 雙擊 `start_daemon.bat` 開常駐 cmd
2. 看到「ready - waiting for tasks...」表示 daemon 待命
3. **不要關 cmd 視窗**

**我 (阿地) 操作 (隨時)**:
- bash 寫 `_queue/X-XX.json` → daemon 30 秒內處理
- 完成後 `_done/X-XX.json` 出現 + 圖在 `_API生圖_*/`

### Daemon 設定
- Model: `gemini-3-pro-image-preview` (Nano Banana Pro, 跟阿美 同引擎)
- ⚠️ NOT `gemini-2.5-flash-image-preview` (是 cheap 版)

## 7. 失敗教訓

### 教訓 1: LoveArt 圖 403 + tainted canvas
- LoveArt URL 直接 fetch → 403 (cookie 不傳)
- IMG 大部分 tainted (CORS), canvas 不能 toDataURL
- 18/1403 張 IMG 有 crossOrigin (能抓), 大部分不行
- **下載 LoveArt 圖太難, 放棄**, 直接 Gemini 重做

### 教訓 2: chrome 存檔對話框跳出來
- 點 LoveArt 圖右下角下載按鈕 → chrome 跳「另存新檔」對話框
- 阿元 「關了又跳出來」極困擾
- **死命令**: 不再點 LoveArt 任何下載按鈕

### 教訓 3: 阿美妹妹 跟著 chat 上下文標題
- 1e350d3c 上次工作篇 13-3
- 我送 9-01 沒明確標, 她跑成「篇 13-4」(內容對, 標題錯)
- 解法: prompt 開頭明寫「【篇 X 第 N/12 張 — 標題】」

### 教訓 4: 阿美弟弟 先描述再確認
- 849414f5 新 agent, 預設「先解釋畫面細節再問需要調整嗎」
- 解法: 先送一個指令「請直接生成 不要再問」
- 之後她會直接生成

### 教訓 5: 連續 reload 升級 CAPTCHA 偵測
- 阿元 5/29 警告
- Reload 1 次 OK, 連續 reload LoveArt 會升級為 hCaptcha (需人勾)

### 教訓 6: Lexical editor cp950 emoji 問題
- Python 在 Windows 預設用 cp950 編碼
- emoji print 會 `UnicodeEncodeError`
- 解法: .bat 設 `PYTHONIOENCODING=utf-8`, Python script 不用 emoji print

### 教訓 7: 圖檔名 emoji/特殊字導致 cowork present_files 失敗
- 簡體/繁體字 (脫/脱, 啓/啓) 編碼差異
- 解法: 檔名用純 ASCII 或一致繁體
