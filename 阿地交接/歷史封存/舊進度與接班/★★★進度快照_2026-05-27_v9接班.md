## 🛠️ 核心操作 SOP (Chrome MCP)

### 1. 每次 send 前必做
```javascript
// inspect 座標 (chat 區 reflow 後位置變)
const editor = document.querySelector('[contenteditable=true]');
const er = editor.getBoundingClientRect();
const editor_x = Math.round(er.x + er.width/2);
const editor_y = Math.round(er.y + er.height/2);
```

### 2. Send 流程 (絕對遵守順序)
```
1. chrome computer left_click [editor_x, editor_y]  ← focus editor
2. chrome computer key "ctrl+a"  ← 選全部 (清空殘留)
3. chrome computer key "Delete"  ← 刪除
4. chrome computer type "..." ← CDP type 一行式 prompt
5. wait 2 秒
6. JS editor.focus()
7. JS sendBtn.click() ← 用 JS 而非 chrome left_click 更可靠
8. wait 5 秒
9. JS check editor_len=0 + thinking=true → 確認送出
```

### 3. ⛔ 死命令
- **Send 只點 1 次** (第 2 次 = cancel!)
- **不用 \n 在 prompt 內** (Lexical 會截斷送出第一段)
- **每張 inspect editor 座標** (位置會變)
- **JS sendBtn.click() 比 chrome left_click 更可靠**
- **DataTransfer paste 會觸發 hCaptcha** (除非必要不用)
- **絕對不信阿美 自評** (要主身親眼看)
