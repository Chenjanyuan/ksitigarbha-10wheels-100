## 📖 Step 6 — LoveArt 操作 SOP (你最常用!)

### 送長 prompt 給阿美 (鐵則 — 1000+ 字必用 clipboard 法)

```javascript
// Step 1: focus LoveArt tab + 寫 clipboard
(async () => {
  const text = `你的 prompt 內容 1000+ 字...`;
  await navigator.clipboard.writeText(text);
  return 'wrote ' + text.length;
})();

// Step 2: 滑鼠 click 編輯器 (focus)
computer.left_click([1250, 720])  // editor 區域

// Step 3: 清空舊內容
computer.key("ctrl+a")
computer.key("Delete")

// Step 4: 貼上
computer.key("ctrl+v")
computer.wait(2)

// Step 5: 確認進去 (檢查 editor 字數)
const editor = document.querySelector('[contenteditable="true"]');
editor.innerText.length  // 應該 = 你 prompt 字數

// Step 6: 按 send 按鈕
computer.left_click([1444, 789])  // 座標 click 比 JS click 穩
computer.wait(3)

// Step 7: 確認送出 (editor 應清空, "思考中..." 出現)
```

### ⚠️ 重要警告
- ❌ `execCommand insertText` 對 1000+ 字會失敗 (回 true 但只進 1 字)
- ❌ JS `button.click()` 可能按到隔壁的「模型選擇」按鈕
- ✅ 用 clipboard + ctrl+v + 座標 click (1444, 789)
