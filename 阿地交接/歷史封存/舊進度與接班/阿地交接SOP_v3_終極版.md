## 7. ★ 5 大常見問題 + 客服解法

### 🚨 問題 1:本願經 vs 十輪經誤植
**症狀**: 不小心寫了婆羅門女、光目女、悲華等故事
**1 號教訓**: 我犯過這個錯,阿元說「確認刪除 重來喔」,我重寫了 60+ 篇 docx
**客服解法**:
1. 寫每篇前先打開 `地藏十輪經連載/100篇大綱.md` 確認主題
2. 不確定就 grep 該篇 docx 原檔內文
3. 經文有疑問就讀 `地藏菩薩本願經.txt`(其實是十輪經全文,檔名有誤)

### 🚨 問題 2:LoveArt 送出按鈕 = 取消按鈕(同位置)
**症狀**: 點第二次,阿美「生成任务已取消」
**1 號教訓**: 我在篇 6 第 8 張犯過,差點被阿元罵
**客服解法**:
- 點 (1550, 580) **只能點一次**!
- 點完後檢查 `el.innerText.length` — 變 0/1 就成功送出
- 不確定就 wait 5 秒看 LoveArt panel 有沒有新項目跑

### 🚨 問題 3:LoveArt selector mode 卡 send(2 號發現)
**症狀**: 阿美給選項按鈕(虛空藏菩薩?/彌勒?...), Chrome MCP 怎麼點都沒反應, send button 從 DOM 消失
**2 號發現**: React state 沒同步,JS click() 不觸發 synthetic event
**客服解法(優先級)**:

**🥇 方法 D 預防 (最重要,90% 不會遇到)**
每張腳本結尾必加:「✅ 直接生成, 不要問我選項!」

**🥈 方法 A computer-use 真實座標點 (95% 解)**
```javascript
// Step 1: JS 抓座標
const btn = [...document.querySelectorAll('button')]
  .find(b => b.innerText.includes('虛空藏菩薩'));
btn.scrollIntoView({ block: 'center' });
const rect = btn.getBoundingClientRect();
const x = Math.round(rect.left + rect.width/2);
const y = Math.round(rect.top + rect.height/2);
```
```
// Step 2: computer-use 點實體座標 (加 Chrome toolbar offset ~80)
mcp__computer-use__left_click({ coordinate: [x, y + 80] })
```

**🥉 方法 B native event dispatch 序列 (80% 解)**
```javascript
const btn = [...document.querySelectorAll('button')]
  .find(b => b.innerText.includes('虛空藏菩薩'));
['pointerdown','mousedown','pointerup','mouseup','click'].forEach(type => {
  btn.dispatchEvent(new MouseEvent(type, {
    bubbles: true, cancelable: true, view: window,
    button: 0, buttons: 1
  }));
});
```

**🚨 方法 E 終極退路:請阿元 UI 上手動點 (100% 解)**
**不要硬幹卡 10 分鐘!** 在聊天說:
> 「阿元 🙏 LoveArt 進入選項模式, Chrome MCP 點不動, 可以幫我手動點『XXX』那顆嗎? 之後我繼續監看」
阿元 1 秒解決,你的 context 留給後面 1100 張腳本。

### 🚨 問題 4:Chrome MCP type 中文字亂掉
**症狀**: 「未曾」→「秦」、「苾芻」→「芾芻」
**1 號發現**: Chrome MCP 的 `type` 對部分中文字符有 bug
**客服解法**:
- 改用 JavaScript: `document.execCommand('insertText', false, text)`
- 或 **2 號發現的更穩做法**: 真實鍵盤 `computer:type` (React state 一定同步)

### 🚨 問題 5:阿美「生成中遇到错误」x3
**症狀**: 同一張腳本連 3 次失敗
**1 號教訓**: 篇 6 第 4 張就這樣
**客服解法**:
- 簡化腳本(刪掉一些細節描述)
- 重送
- 若還失敗,跟阿美說「我們換個寫法重試 🌸」附簡版腳本
