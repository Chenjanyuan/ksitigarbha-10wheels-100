# 🪷 地藏經漫畫 — LoveArt 自動生圖（網頁介面版）

> 阿研 for 阿元 / 2026-06-10
> **只要雙擊一個檔，剩下全在網頁上點按鈕。** 不用碰命令列。

---

## 怎麼開始（超簡單）

### 第 0 次：確認有 Python
開「命令提示字元」打 `python --version`，有版本就 OK。
沒有 → 去 python.org 下載安裝（安裝時記得勾 **Add Python to PATH**）。

### 每次要用：雙擊 **`▶ 啟動生圖網頁.bat`**
- 它會自動打開一個網頁（你的瀏覽器）。
- 會跳一個**黑色小視窗**——那是後台，**別關它**（關了網頁就停）。
- 之後全部在**網頁上點按鈕**就好。

---

## 網頁上做 4 件事

**① 設定金鑰（只需一次）**
把你的 LoveArt **access_key（ak_…）** 和 **secret_key（sk_…）** 貼進去，按「儲存金鑰」。
（在 LoveArt 頭像 → Lovart 龙虾 → AK/SK Management 拿。存在你電腦，已設定不上傳 GitHub。）
👉 第一次還要按一下「**下載生圖程式**」（把官方 agent_skill.py 抓下來，只需一次）。

**② 生圖**
選一篇（或「全部缺圖的篇」）→ 按「**▶ 開始生圖**」→ 下面即時看進度。
（會自動跳過已生過的，只補缺的。**第一次先選一篇試**。）

**③ 每晚自動跑**
按「🌙 開啟每晚01:30自動」→ 以後半夜電腦自動生圖（那時電腦要開著、可關螢幕）。

**④ 看生出來的圖**
選一篇，下面就顯示那篇「圖片」資料夾裡的圖（縮圖）。

---

## 它在做什麼（白話）

讀阿地寫好的 **`生成命令_LoveArt.md`** → 自動把 `@佛陀／@地藏／@飽和度參考…` 對應到「人物角色卡」的 PNG、上傳當參考圖 → 用 **LoveArt 免費無限模式 + Nano Banana Pro** 生圖 → 存進該篇「圖片」夾，照你們命名。
**完全照你們手動那套，只是改成自動。**

---

## 提醒

- 🧪 這程式阿研**沒法在雲端幫你實測**（只有你電腦連得到 LoveArt）。**第一次先試一篇**，有狀況我們一起 debug。
- 🔤 圖上繁體字偶爾會糊／錯（AI 通病）→ 失敗的那幾張隔天再生一次（只補缺的）。
- 🔐 secret_key 只存你電腦（`金鑰.txt`，已設定不上傳 GitHub），別外傳。
- 角色卡對應寫在 `生圖介面.py` 最上面 `CARD_MAP`，要加菩薩在那改一行。
