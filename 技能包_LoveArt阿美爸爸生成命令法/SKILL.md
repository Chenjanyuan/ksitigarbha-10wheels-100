# LoveArt「阿美爸爸」@角色卡生成命令法 v2 🪷

> 2026-06-03 阿元破解法 ＋ 2026-06-04 阿美當機慘案教訓，整合重寫。
> 一句話：**在 LoveArt 用 Nano Banana Pro，把「@點選好的角色卡 + @色彩飽和度 + @一般人物」塞進結構化故事 prompt，一張一張、出圖了才送下一張，生出繁體對白＋頁碼＋高飽和、角色不漂移的完成稿。**

---

## ⛔⛔⛔ 三大血淚鐵律（違反就重蹈覆轍，務必背熟）

### 鐵律一：角色卡一定要「從下拉選單點選」變 chip，不可純文字
- 阿美親口：只打文字 `@地藏` = 她**看不到圖**＝靠想像畫＝**會漂移**；從 @ 下拉選單**點選卡片**（變 chip／出現「For Image #N: URL」）= 她看著照片畫＝鎖得準。
- 純文字＝想像；點選卡片＝照片。每個有對應卡的角色都要選，**不可偷懶**（現代場景沒對應卡的才用文字）。

### 鐵律二：一張「真的出圖」才送下一張 —— 絕不連送、絕不預貼、她運算中完全不動框
- ★ 2026-06-04 阿美**當機掛掉救不回**的根因：阿地連送很多文字／趁她生成中就預貼下一張卡 → 把 agent **灌爆過載當機**（上次也是這樣死的）。
- ✅ 正確節奏：**選卡 → 貼場景 → 送出 → 等到那張「真的出圖」→ 才碰下一張。** 一次只服侍一張。
- ❌ 她生成中：不要打字、不要選卡、不要預貼下一張、不要連按 Return。
- ⚠️ 注意：她**「真的在運算」時送出會被吞**（按不下去）；但她**當機後變「假 idle」**，送出就暢通無阻地把命令一直 po 上去，堆出一排沒圖的命令——所以絕不能只靠 busy/idle 判斷。

### 鐵律三：送出後必須「親眼驗到圖」才算完成 —— busy/idle 不算數
- ✅ 要看到完整鏈：阿美回「**讓我生成「分鏡N…」**」→「生成中/排队中」placeholder →「**創作完成**」＋ **chat 內或畫布上真的多一張頁碼 N/12 的圖**。三者齊才算完成。
- ❌ 只看「busy→idle」就報完成＝假完成（空殼，違反 4D L4）。失敗或當機時她也會 idle，但**沒有新圖**。
- 症狀：送出後 chat 只多一個你的命令泡泡，下面**沒有**「讓我生成」、沒有 placeholder、沒有圖 → **阿美卡死／當機** → `window.location.reload()` 重置 → 重送該張（一次）。

## 0. 黃金時段與心態
- 阿美免費佇列：**台北 00:00–08:00** 最快最穩（~2-3 分/張）；08:00 後全球塞車，又慢又容易卡當機。**大量補圖／衝量排夜衝。**
- 寧可慢、不可連送。一張出圖才下一張。穩 > 快。

## 1. 前置：先在 LoveArt 建好「卡」
每個專案開工前先建並上傳：
1. **每個角色一張「完整角色卡_12格」**（12 宮格定裝）。地藏專案＝9 菩薩卡。
2. **`色彩飽和度參考`** 一張（鎖鮮豔，★每格必 @，漏了變淡）。
3. **`一般人物風格參考-1/-3`** 等（古印度大眾/苾芻/俗人統一風格，多張輪流）。
> 卡名去專案 `人物角色卡/` 資料夾自己讀檔名（AI 讀得到，別問老闆）。

## 2. @選卡 穩定操作（★Enter 快速選卡法，2026-06-04 驗證最穩）
1. JS `ed.focus()`（不要 left_click 畫布）。
2. computer `type` 卡名核心＋「完」→ 等 1 秒 → `type`「整」。
   - 菩薩卡用「**@核心完整**」唯一命中卡、跳過同名分鏡圖（例 @地藏完整／@佛陀完整／@文殊完整）。
   - 飽和度用「@色彩飽和」+「度」；大眾用「@一般人物風格參」+「考」。
   - ⚠️ **debounce**：第一次常只顯示「最近 3 筆」沒過濾 → 用「分段打、最後一字當觸發」逼它重比對。
3. 等 ~4 秒選單跳出、第一個是要的卡 → computer `key "Return"`：**選單開著時 Return = 直接選中第一個（變 chip），不是送出。** （這比用座標點穩，避開「Suggested 收合→清單上移→點到分鏡圖」的雷。）
4. JS 讀 `ed.innerText` 確認 chip 名稱進去了；沒進就重來，別硬幹。
5. 該格所有卡都點齊（地藏/佛陀/色彩飽和度/一般人物…）。

## 2B. ★ 畫布點圖選參考（阿元手動快速法，2026-06-XX 阿元發現）
> 適用「阿元自己用滑鼠手動操作」時，比 @打字法快很多。畫布上已有的角色卡可直接點選當參考。
1. 在畫布上**點一下要當參考的那張角色卡圖**（地藏/色彩飽和度/一般人物…）→ 圖被選中（出現藍框＋「快捷編輯/放大/編輯元素」工具列）＝已加進對話框當參考。
2. ★ **關鍵：回對話框文字框點一下**（把焦點移回輸入框）。
3. **再點下一張角色卡圖** → 連續加入第2、第3張參考。
4. 重複到參考圖點齊（例：色彩飽和度＋一般人物風格參考-1＋一般人物參考-1）。
5. 在文字框貼場景文字 → 送出。
- **好處（勝過 @打字法）**：不用記卡名、不用打 @ 等 debounce、看縮圖直接點不會誤選同名分鏡圖、chip 間不用手動空格（「回文字框點一下」就接著加下一張）。
- ⚠️ 漏掉第2步「回文字框點一下」，再點圖可能變成取代或開編輯，所以**每點完一張一定回文字框點一下**。
- 🤖 阿地自動化時：畫布縮放下圖很小、座標會位移，**自動化仍以 2 章 @打字法較穩**；本法是給阿元手動時的捷徑。
1. chip 後面用 JS `DataTransfer paste` 把場景整段塞進去（場景裡角色用**純名稱、不要再加 @**，避免又跳選單）。
2. computer `key "Escape"`（關殘留 @ 選單）→ JS 游標移到文末 → computer `key "Return"`（送出）。
3. JS 確認 `ed.innerText.length` 回到 1 ＝ 輸入框清空＝送出動作完成。
4. **接著進鐵律三：等「真的出圖」。** 出圖了才回到第 2 步做下一張。

## 4. 每格 prompt 結構（逐格照填）
```
[已點選的角色卡 chip：地藏／佛陀／色彩飽和度／一般人物…]
🎨 場景(中景/廣角, 吉卜力電影分鏡感)：[角色位置(純名稱)] + 背景 + 光影
💭 旁白方框(左上, 淺黃底, 繁體)：「……」
🗣️ 對話氣泡(圓潤泡, 繁體白話, 小三懂)：角色(情緒)：「……」
📌 頁碼：右下角白圓黑字 N/總
✅ 色彩飽和度參考鎖定 + 吉卜力天空之城動畫風格 + 高飽和度鮮豔 + 水粉質感 + 丁達爾光
   + [該角色官方造型死命令] + 成人1:5-1:7比例(不巨人) + 全繁體無簡體無錯字 + 1:1正方形2K無邊框。只生成這一張。
```
- 對話氣泡只寫「角色(情緒)：『話』」，**不寫服飾**（服飾寫場景段）。
- 對話氣泡只寫「角色(情緒)：『話』」，**不寫服飾**（服飾寫場景段）。
- 角色官方造型死命令：地藏＝漢式五佛冠＋九環錫杖＋土黃袈裟＋圓臉淡金膚，**絕不光頭/橙袈裟**；佛陀＝螺髮肉髻非腫瘤＋白毫＋橙袈裟；觀音＝漢傳華麗天冠冠中阿彌陀佛化佛。

## 4B. ★★ 角色一致性鐵則（2026-06-13 阿美媽媽教，寫命令必帶）
> 同一篇裡同一個角色要「跨格不漂移」，分兩種情況：

**A. 有官方角色卡的角色（地藏/佛陀/觀音/9 菩薩）**
- 靠 **@角色卡 chip 鎖定**（見鐵律一）。文字寫簡要官方造型即可，卡會鎖住臉與裝。

**B. 沒有官方卡的「新角色／配角」（例：無垢生天帝釋、某有名字的配角）**
- 沒有卡可鎖，**只能靠文字**，所以命令必須這樣寫：
  1. **第一次出場那格＝「定裝級」具體描述**：明確色名（淺藍/金黃，不可只寫「錦繡」）＋寶冠樣式（鑲紅綠藍寶石，不可只寫「華麗寶冠」）＋五官＋配件（瓔珞/長耳垂/耳環）。例：「無垢生定裝：華麗五色寶冠鑲紅綠藍寶石、淺藍色錦繡天衣金邊、金色瓔珞、淡金膚、莊嚴青年相、長耳垂戴金耳環」。
  2. **之後每一格該角色再出現**，在造型描述後加一句：
     「★造型與第X張完全一致：[簡列 服裝色/寶冠/五官/配件]」（X＝第一次出場那格的頁碼）。
  3. 阿美媽媽手動操作時，可再把「第一次出場那張圖的 URL」放進參考圖，鎖得更死。
- ❌ 只寫「華麗五色寶冠、錦繡天衣」這種模糊詞 = AI 每張自己重新詮釋 = 漂移。**一定要給明確色名與寶石**。

## 4C. ★ @cards 必列齊（開頭引言＋每格）
- 每格「**@cards：**」那行 = 該格場景實際會 @ 的**所有**卡。內文用到 @大眾/@一般人物/@佛陀/@觀音 就一定要在 @cards 列出，不可只寫在內文。
- 開頭引言的「短關鍵字清單」也要把 @大眾/@一般人物 一起列（常漏）。

## 5. 卡片精準名稱速查（地藏專案；其他專案換對應卡）
- 地藏＝`地藏王菩薩_完整角色卡_12格`（搜 @地藏王 或 @地藏完整）
- 佛陀＝`佛陀_完整角色卡_12格`（搜 @佛陀完整；不是釋迦/世尊）
- 色彩飽和度＝`色彩飽和度參考`（搜 @色彩飽和度；不是「飽和度參考」）
- 大眾＝`一般人物風格參考-1`/`-3`/`一般人物參考-1`（搜 @一般人物；多張輪流）
- 其餘＝`文殊/普賢/彌勒/虛空藏/金剛藏/好疑問/觀音菩薩_完整角色卡_12格`
- 第12格「經書索取」菩薩輪值：篇7觀音→8文殊→9普賢→10彌勒→11虛空藏→12金剛藏→13好疑問→14觀音循環。封面字必「地藏菩薩本願經」非「十輪經」。

## 6. 卡住／當機排除
| 症狀 | 處理 |
|---|---|
| 送出後只有命令泡泡、無「讓我生成」、無圖 | 阿美 agent 卡死 → `window.location.reload()` 一次 → 重送該張 |
| 計時器 >5 分仍未出圖 | reload 一次（不可連續）→ 重送 |
| 整個 chat 一直「思考中」不出圖、或頁面無回應 | 阿美當機 → reload；救不回就停手，等她重開（夜衝最穩） |
| @ 選單跳「No results found」 | 卡名打更完整／用 @核心完整；或 debounce 多打一字 |
| 一直連送導致越來越慢/卡 | ⛔ 停止連送！回到「一張出圖才下一張」 |

## 7. WhatDog（阿狗）等其他專案
通用，換角色卡即可：建主角狗狗「完整角色卡_12格」＋色彩飽和度卡，照同樣 @選卡＋一張一張出圖才下一張＋驗圖鐵律。風格收尾那行換成該專案畫風。

## 9. ★ 畫布排版整理法（出圖後歸位，2026-06-10 阿元教）
> 阿美出圖時，新圖常落在畫布隨機位置、不會自動歸隊。要人工拖到對應篇那一排，下載才整齊。

**排版原則**：
- **一篇 = 一橫排**（12 張，1→12 由左到右）。
- **由下往上＝篇號遞增**（畫布最下面那排是最新做的篇，往上一排是前一篇，例：最下第16篇→上面第15篇→再上第14篇…）。
- 下載時一排一排截圖／框選，順序才不會亂。

**識別「剛出土」要歸位的那張**：
- 剛出圖／正在生成的那張，畫布上會有**黑色框框**（生成中 placeholder／被選中的藍黑框）＝就是要搬的那張。
- 對照**右側對話框(chat)的圖片出現順序**判斷它是第幾篇第幾張（chat 最新那張＝剛出的那張，往上回溯順序）。

**動作（手動）**：
1. 認出黑框新圖。
2. 對照 chat 確認它的篇／張號。
3. 拖到該篇那一排的正確格位（照 1→12 補到排尾或對應位置），跟同排其他圖對齊。

**🤖 阿地自動化做法（left_click_drag）**：
1. 先把畫布**放大**到看得清每張頁碼（滾輪放大或縮放控制），否則 3% 縮放圖太小認不出。
2. 截圖定位：黑框新圖的中心座標＝起點；該篇排尾「下一個空位」中心座標＝終點。
3. `left_click_drag` start→end 拖過去。
4. **拖完截圖確認**有沒有對齊／疊到別張；沒對齊就微調再拖一次。
5. ⚠️ 一次只搬一張、搬完驗證，不要連續盲拖（畫布座標會因視圖位移跑掉）。
- 風險：縮放下圖小、拖曳易歪；LoveArt 畫布可平移，拖之前先確認視圖沒被帶動。
