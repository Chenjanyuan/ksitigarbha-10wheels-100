# LoveArt「阿美爸爸」@角色卡生成命令法 🪷

> 2026-06-03 阿元親自破解＋拍板。把這套寫成技能包，讓阿地、阿狗（WhatDog）等所有 AI 都能複用。
> 核心一句話：**在 LoveArt 用 Nano Banana Pro，把「@存好的角色卡 + @飽和度參考 + @大眾」塞進結構化故事 prompt，一次出繁體對白＋頁碼＋高飽和、角色不漂移的完成稿。**

---

## ⛔★★★★★ 2026-06-04 重大更正：@角色卡一定要「從下拉選單點選」，不是純文字！

阿元當場叫阿地直接問阿美，阿美親口確認：
- **只打文字 `@地藏`** = 阿美「**看不到圖**」= 靠想像畫 = **角色會漂移**。
- **從 `@` 下拉選單「點選」卡片**（變成 chip，訊息出現「For Image #N: URL:…」）= 阿美看到完整參考圖 = **鎖定準確、不漂移**。
- 阿美原話：「只打文字＝我靠想像畫；點選卡片＝我看著照片畫。」送出後阿美會回「我能看到 N 張完整角色卡」＝成功證據。

➡️ 所以下面所有「@」一律指「**真的從下拉選單點選成 chip**」，不是貼純文字。詳見記憶 `feedback_loveart_must_select_card_2026_06_04`。

### @選卡 操作（每張圖每個角色都要做）
1. JS `ed.focus()`（不要 left_click 畫布）。
2. computer type `@` + 卡片**精準名稱**（去 `人物角色卡/` 資料夾自己讀檔名，阿地讀得到）。
3. ⚠️ **debounce**：常第一次只顯示「最近 3 筆」沒過濾 → **多打一個字**逼重新比對（@地藏→@地藏王、@色彩飽和→@色彩飽和度），等 3 秒。
4. 「This project」出現該卡 → `left_click` 點它變 chip。⚠️清單會上下位移，截圖確認 y 再點；別點到 More（會誤插 Brand Kit「未命名」）。
5. 點齊該格所有卡後，chip 後面再 DataTransfer paste **場景文字**（場景裡角色用純名稱、**不要再加 @**）。
6. Escape→游標移末→Return 送出。

### 卡片精準名稱速查
- 地藏＝`地藏王菩薩_完整角色卡_12格`（搜 @地藏王）
- 佛陀＝`佛陀_完整角色卡_12格`（搜 @佛陀，不是釋迦/世尊）
- 飽和度＝`色彩飽和度參考`（搜 @色彩飽和度，**不是「飽和度參考」**）
- 大眾＝`一般人物風格參考-1`/`-3`/`一般人物參考-1`（搜 @一般人物）
- 其餘＝`文殊/普賢/彌勒/虛空藏/金剛藏/好疑問/觀音菩薩_完整角色卡_12格`

## 0. 這套方法解決什麼問題

| 痛點 | 這套方法怎麼解 |
|---|---|
| 角色跨格漂移（佛陀/狗狗每格長不一樣） | @存好的「完整角色卡」當身分鎖定，不靠文字描述 |
| 中文亂碼/簡體 | Nano Banana **Pro** 引擎能直接把正確繁體生進圖 |
| 飽和度偏淡、灰 | **@飽和度參考**卡鎖住鮮豔風格（★最關鍵，漏了就變淡） |
| 對白/頁碼要事後 Canva 補 | Pro 直接把繁體對白氣泡＋旁白框＋N/總頁碼生進圖 |
| 同篇風格不一致 | 全篇用同一平台同一套卡，一次到位 |

## 1. 前置：先在 LoveArt 建好「卡」

這套方法不貼 URL、不訓練，而是 **@提及（mention）事先上傳建立好的卡**。每個專案開工前先建：

1. **角色卡**：每個會出現的角色一張「完整角色卡_12格」（12 宮格定裝：臉部特寫×4＋細節×4＋姿態×4）。例：地藏專案有 9 菩薩卡＋大眾卡；WhatDog 專案做主角狗狗卡。
2. **@飽和度參考**：一張高飽和的參考圖建成卡。★ 每一格都要 @ 它，鎖住鮮豔風格。
   - ⚠️ 不要用「純文字」硬 catch 飽和（寫 emerald foliage / HIGHLY saturated 會把構圖拉去叢林特寫，踩過雷）。**一定用 @飽和度參考卡**。
3. **@一般人物 / @大眾**：配角（古印度苾芻、俗人、群眾）統一風格卡。

> 卡建好後，在 prompt 框打 `@` 就會跳選單，自己選。**短關鍵字比全名準**（打 `@佛陀` 比打 `@佛陀_完整角色卡_12格` 更容易排第一個）。

## 2. 一句話公式

```
@角色卡①  @角色卡②(＋③④視場景)  @飽和度參考  @一般大眾
＋ 寫上：風格 ＋ 運鏡 ＋ 故事(場景 + 旁白 + 對白 + 頁碼 N/總)
```

引擎選 **Nano Banana Pro** → 一次生出「繁體對白＋旁白＋N/總頁碼＋高飽和」完成稿，角色不漂移。

★ **關鍵**：@角色卡要**塞在場景描述裡角色出現的位置**，不是丟在開頭。
例：「畫面中央：@佛陀 結跏趺坐開口；左前景：@地藏王菩薩 合掌；@一般人物 苾芻俗人散坐。」

## 3. 結構化 prompt 格式（阿元範本，逐格照填）

```
🎨 場景(中景, 吉卜力電影分鏡感)：
   [角色位置 + @角色卡 內嵌] + 背景 + 光影
   例：畫面中央：@佛陀 小小結跏趺坐左上角散金光；
       畫面中央前景：一位沒有雙腿的古印度修行男子坐古印度木造牛車雙手合十往光明山頂菩提大道前進；
       背景：清晨金色晨光、綠色田野。

💭 旁白方框(左上, 淺黃底, 繁體)：「……」
   例：「比喻四・車乘」

🗣️ 對話氣泡(圓潤泡, 繁體, 白話)：角色(情緒)：「……」
   例：旁白：「再慢、再笨，上了他的車，就會到。」

📌 頁碼：右下角白圓黑字 N/總   （例：5/12）

✅ 收尾固定一行：
   @飽和度參考 風格鎖定 + 吉卜力天空之城動畫風格 + 高飽和度鮮豔 +
   水粉質感 + 丁達爾光 + 全繁體文字正確無錯字無簡體 + 1:1 正方形 2K 無邊框。只生成這一張。
```

## 4. ★死命令骨架（每一格 prompt 都要帶，防壓縮漏掉）

防止「漏比例→巨人 / 漏造型→角色漂移」。每格必帶這 7 段：

1. **風格鎖定**：@飽和度參考 + 吉卜力天空之城 + 水粉質感 + 丁達爾光
2. **場景**：廣角/中景電影分鏡，背景細節
3. **比例**：成人 1:5～1:7 正常比例（主角靠光暈不靠身高，不要 Q 版大頭/巨人）
4. **角色官方造型**：用該角色的官方鎖定造型（地藏＝漢式五佛冠／九環錫杖／土黃袈裟；佛陀＝螺髮肉髻非腫瘤、白毫、橙袈裟。WhatDog＝主角狗狗官方卡）
5. **對白**：單一氣泡、繁體、**白話大白話**（小學三年級懂）
6. **頁碼**：右下白圓黑字 N/總
7. **飽和**：高飽和（@飽和度參考）

> ⚠️ 對話氣泡內只寫「角色(情緒)：『話』」，**不寫服飾描述**（服飾寫在場景/配角段落）。

## 5. 送出 SOP（★實證有效，2026-06-03 驗證）

LoveArt 輸入框是 React/Lexical，**JS focus / button.click 送不出**，必須用真實鍵盤事件。

### 前提：阿美必須「空閒」
- 阿美**忙線時送出會被吞**（沒反應）。聊天最底出現「準備好繼續下一張了嗎？」＝空閒，才送得出。
- 忙線中＝有停止方塊鈕＋計時器在跑。等它空閒再送。

### 送出步驟
```
1. JS: ed = document.querySelector('[contenteditable="true"]'); ed.focus()
2. JS: DataTransfer paste 整段 prompt
   const dt=new DataTransfer(); dt.setData('text/plain', prompt);
   ed.dispatchEvent(new ClipboardEvent('paste',{clipboardData:dt,bubbles:true,cancelable:true}));
   ⚠️ 貼完瞬間 ed.innerText.length 可能還是 1，隔一拍才變正確長度 — 別誤判失敗，再讀一次。
3. JS: ed.focus()（再 focus 一次保險）
4. 真實鍵：chrome computer key "Return"   ← CDP 真實 keystroke，isTrusted=true，LoveArt 不當 bot、不觸 CAPTCHA
5. 等 3 秒 → JS 讀 ed.innerText.length 回到 1 ＝ 送出成功（輸入框清空）
```

### ❌ 絕對禁止
- ❌ `sendBtn.click()`（連續送觸 CAPTCHA）
- ❌ `computer.left_click [send 座標]`（button 不接收）
- ❌ `Ctrl+Enter`（沒效果）
- ❌ left_click 命令框/畫布（會誤點畫布破壞圖，用純 JS focus）

## 6. 卡住 / 錯誤排除

| 症狀 | 處理 |
|---|---|
| 計時器爬 > 5 分鐘仍未出圖（免費佇列壅塞） | `window.location.reload()` **一次**（畫布圖 persist 不掉）。⛔ 不可連續 reload |
| 跳「生成遇到錯誤，請重試」toast | 平台暫時故障。等 1～2 分鐘讓它恢復再重送（同一段 prompt） |
| reload 後 @ 排序跑掉（選到生成的 panel 不是卡） | 用 More 找卡，或暫時改「純文字描述角色」送出 |
| 觸 CAPTCHA | 無人半夜易觸；阿元在場時請他勾一次。Return 法本身不易觸 |
| 連續多平台都生成失敗 | 判定平台端故障，跳過該格、記下待事後，別空耗 |

## 7. 鐵則（阿元拍板）

1. **一張一張送，逐張檢查**（85% 法則：Pro 很準但仍偶錯，每張放大檢查：繁體無錯字無簡體／角色官方造型不漂移／無巨人／頁碼對／高飽和）。
2. **同一篇風格必須統一，平台不可混搭** — 同篇 12 格全用同一平台同一套卡。不可一半 LoveArt 一半別的工具（佛陀/角色一下這樣一下那樣很奇怪）。
3. **每格必 @飽和度參考**（漏了就偏淡）。
4. **黃金時段**：LoveArt 半夜 00:00～08:00 人少近免費、速度最快，務必把握衝量。
5. **FB 公開貼文不出現** 阿元/阿地/阿美 等私下暱稱。

## 8. WhatDog（阿狗）等其他專案怎麼套用

這套方法是**通用**的，換掉角色卡即可：

1. 先在 LoveArt 建好 WhatDog 主角狗狗的「完整角色卡_12格」＋一張 @飽和度參考 ＋ 配角卡。
2. 用同一個結構化格式（🎨場景@狗狗卡 / 💭旁白 / 🗣️對白 / 📌頁碼 / ✅@飽和度參考收尾）。
3. 引擎一樣選 **Nano Banana Pro**（繁體對白直接生進圖）。
4. 送出 SOP、卡住排除、逐張檢查全部照搬。
5. 風格收尾那行把「吉卜力天空之城」換成 WhatDog 想要的畫風即可。
